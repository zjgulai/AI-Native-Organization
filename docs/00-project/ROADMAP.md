# 方案形成路线

状态：总体战略框架已连续形成并确认。以下是决策和实施依赖，不要求逐阶段停下来访谈；实际经营验证与生产实施仍按各自条件推进。

| 阶段 | 要解决的问题 | 主要产物 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| P0 项目建立 | 如何持续讨论并保留上下文 | 目录、AGENTS、Git、设计树 | 文件和分支检查通过 |
| P1 目标与现状 | 50 指什么；何为同等经营成果；业务实际有多复杂 | 人数边界、事实基线、指标、目标约束 | 用户确认目标与边界，未知项有负责人或取数路径 |
| P2 场景与价值流 | 从机会到回款如何流动；哪里耗人、慢或易出错 | 场景目录、价值流、异常量、优先级 | 选出具有基线且可验证的首个闭环 |
| P3 Agent组织与外部执行 | 哪些职责由50个逻辑岗位承接；哪些由系统/外部主体执行 | Role Profiles、运营/管理/治理视图、外部执行边界与经济性测算 | 关键场景有唯一主岗位、策略与回执路径 |
| P4 分身与协作 | 单Case Agent如何通过人格、Skills、Playbook和工具产生稳定结果 | 分身卡、四层图谱、按需Skill装配、Agent管理和资产边界 | 正常和异常场景走查通过，用户决定策略边界 |
| P5 数据与平台 | 数据在哪里；DeepSeek Harness 实际支持什么 | 数据契约、能力差距、可评审配置方案 | 版本和能力有证据，缺口与成本清楚 |
| P6 试点设计 | 怎样证明效果且能冻结、恢复和核对回执 | 基线、评估集、试点协议、验收门槛 | 用户确认具体试点范围与动作策略 |
| P7 实证与迁移 | 场景效果能否持续；Agent、工具与外部执行成本如何变化 | 试点证据、成本与容量复核、迁移路线 | 所选经营指标和风险边界达到约定门槛 |
| P8 方案与 PRD 定稿 | 什么应实施，如何追踪到经营目标 | 完整方案、PRD、需求追踪、实施分期 | 用户确认范围、依赖、验收与未解决事项 |

各阶段不代表固定周数。P0已完成，v1.1保留为历史框架；当前优先通过R05把P3至P4升级为单Case Agent与四层图谱，再进入R04的P5至P6实施参数。P7尚未开展，P8实施版须吸收真实验证结果。50已明确为逻辑AI岗位类型数；运行实例、Delegate、未来真人组织和供应商投入分别核算。
