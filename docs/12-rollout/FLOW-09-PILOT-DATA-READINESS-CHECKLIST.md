## 3. 降级与证据等级联动规则

- 每个 `data_gap` 在产物中标注：缺口项、影响的指标/结论分支、降级后的证据等级（实测→代理→方向性→unknown）。
- **G2 无预算** → L2 认知/考虑度指标全部 `proxy_only`，诊断结论中品牌资产部分只能给方向不给水平。
- **G4 Amazon 不可触达**（已预设）→ 复购/LTV 类假设在 Amazon 侧自动降级为「不可验证」，只能在独立站侧验证——**而独立站当前无数据（N1）**，则 LTV 假设整体挂起。
- **G1 无品牌备案** → 搜索词/市场篮数据缺失，SCN-011 归因设计中 Amazon 侧只能用订单级数据，MTA 不可用只能 MMM/AB。
- 任一硬缺口未核实 → 对应 Case Charter 的 `data_gap_register` 必须登记，不得默认「应该有」。

## 4. 核实执行方式

- **访谈对象**：Amazon 运营负责人、DTC/独立站负责人、品牌/市场负责人、CRM 负责人、IT/数字化中心、法务/合规（渠道数据权属）。
- **证据形式**：后台截图（脱敏）、报表导出样例、工具订阅清单、书面确认邮件；不接受口头「应该有」。
- **时限建议**：实例化 Case 前完成 G1/G4（决定数据架构），G2/G3 可与首个 Case 并行（决定证据等级上限）。
- **产出**：本清单回填「企业回答」列 + 证据链接，更新章程 §7 状态，再进 PILOT-G1 评审。
