# 验证与验收

状态：评估框架草稿；指标、样本和阈值需在业务基线明确后决定。

[PRD](../13-prd/PRD.md)列出26项需求验收条件及首个场景的正常/失败情境；[容量和成本模型](../02-strategy/CAPACITY-AND-COST.md)定义自治负荷、成本与经营效果的独立核算方式。当前通过的文档检查记录在[项目状态](../00-project/STATUS.md)。

| 层次 | 要证明什么 | 不能推导什么 |
| --- | --- | --- |
| 文档与走查 | 职责、数据、权限和异常路径可解释 | 真实执行有效 |
| 离线回放 | 已知输入下的产物和判断符合规则 | 当前真实业务已改善 |
| 影子运行 | 真实信号下的建议、延迟、编队和自治异常可测量 | AI 已获执行授权 |
| 有限实操 | 在明确策略范围内闭环且可冻结/恢复 | 全渠道、旺季或全公司都适用 |
| 扩展与持续经营 | 峰值、长期效果、全成本和组织负荷满足门槛 | 可以自动推广至不同业务边界 |

每次评估记录：场景及版本、业务范围、对照基线、数据窗口、样本选择、核心指标、编队、工具/回执、自治异常、实际成本、限制与验收机制。

自治异常、外部执行和未来HITL分别计入成本；准确率、完成率、等待、冻结恢复和未来可减少编制分别计算。经营效果同时检验收入、利润/贡献、现金占用、客户结果和已确认的约束。
