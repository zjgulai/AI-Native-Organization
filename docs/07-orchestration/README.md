## 图谱需要表达的内容

| 对象或关系 | 需要说明 |
| --- | --- |
| 场景 | 经营目标、触发、开始与结束条件 |
| 主岗位人格 | 唯一经营结果责任、判断风格、产物接收和工单闭环 |
| Case Control | 确定性建单、价值流/主岗位选择、Bundle固定、上下文装配和异常状态 |
| AI 岗位分身 | 主岗位人格、Skills、产物规范、保障规则及适用范围 |
| 业务产物 | 数据口径、版本、证据与接收条件 |
| 阶段交接 | 什么产物在什么条件下被下一阶段接收 |
| 审查与仲裁 | 利益冲突、不同结论与越权问题如何处理 |
| 系统与权限 | 哪个主体可以读取、建议或执行何种动作 |

## 必须走查的具体情境

- 广告建议加预算，但库存不足、补货未确认时如何作出一致决定。
- 同一品牌不同店铺的价格和促销互相影响时谁负责整体结果。
- 同一事件重复到达，或执行后未收到成功回执时如何避免重复动作。
- 多个场景同时请求同一笔预算、同一份库存或同一受控工具时如何排序。
- 分身不可用、数据过期、证据冲突或外部执行主体未响应时如何冻结与恢复。
