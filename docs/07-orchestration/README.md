# 场景编排与协同图谱

状态：Agent-first自主运行基线v1.1已确认；[协同图谱](COLLABORATION-GRAPH.md)及[结构化关系数据](collaboration-graph.json)覆盖50岗位和8流程；[自主运行模型](AUTONOMOUS-OPERATING-MODEL.md)定义动态编队。图中的参与关系不等于实际授权。

## 图谱需要表达的内容

| 对象或关系 | 需要说明 |
| --- | --- |
| 场景 | 经营目标、触发、开始与结束条件 |
| AI结果负责人 | 经营结果、产物接收和工单闭环 |
| AGT-002编排者 | 动态匹配、依赖、状态和自治异常协调 |
| AI 岗位及实例 | 职责、适用范围、任务容量 |
| 业务产物 | 数据口径、版本、证据与接收条件 |
| 任务交接 | 谁交给谁、何时交接、谁验收 |
| 审查与仲裁 | 利益冲突、不同结论与越权问题如何处理 |
| 系统与权限 | 哪个主体可以读取、建议或执行何种动作 |

## 必须走查的具体情境

- 广告建议加预算，但库存不足、补货未确认时如何作出一致决定。
- 同一品牌不同店铺的价格和促销互相影响时谁负责整体结果。
- 同一事件重复到达，或执行后未收到成功回执时如何避免重复动作。
- 多个场景同时请求同一笔预算、同一份库存或同一受控工具时如何排序。
- 分身不可用、数据过期、证据冲突或外部执行主体未响应时如何冻结与恢复。

最终形成业务协作图和运行编排图，分别说明责任关系与实际运行机制，并映射至核实后的平台能力。
