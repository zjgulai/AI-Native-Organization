# 语义契约 · SCN-015 客服、退换货、评价与客诉

## 类1 · 对象与属性（第 1–4 句）

1. 「服务行动包」是 SCN-015 的最终产物（业务实体），它有：逐工单回复草稿、退款/换货/补偿建议（含金额与依据）、退货处置建议、评价回复草稿（合规检查后）、VOC 结构化摘要（主题×证据引用）；每条标注可证伪条件与所需授权级别。【显·SCN-015 §业务闭环 STG-05】
2. 「Service Evidence Pack」是 STG-04 的证据工件，有：工单分类、退货原因、评价主题、解决时长、补偿记录；验收判据为来源齐全率 100%。【显·SCN-015 §业务闭环 STG-04/验收】
3. 「问题四分流」枚举：服务问题（可回复解决）/产品问题（回流 SCN-009/002）/期望问题（回流 SCN-012）/质量事件（升级 FLOW-07 Case，标 `flow07_candidate`）——诊断产物必须归入其一，不得混合。【显·SCN-015 §业务闭环 STG-04】
4. 「SCN-015 Case」为双流绑定场景：常规服务闭环主绑 FLOW-05/AGT-034；客诉聚类指向质量缺陷或账号风险时按 D-025 拆 `correlation_id` 关联的 FLOW-07 Case（AGT-018 质守）——两层结果不得由同一 Case 兼负。【显·SCN-015 §适用说明/责任】

## 类2 · 分层与约束（第 5–8 句）

5. 「PII 最小化」约束（全场景最严）：客户身份/订单/健康相邻信息仅服务目的所需字段；Amazon 买家无站外身份；健康相邻内容最小化且**禁止用于营销画像**；PII 不得导出至聚合分析层。【显·SCN-015 §输入/红线】
6. 「渠道分别建档」约束：客服系统（Amazon Buyer-Seller Messaging/Shopify Inbox/DME 渠道）、订单退货、评价数据各自独立口径建档；跨渠道口径冲突未决前不做合并统计；金额/币种分列。【显·SCN-015 §输入/接管与恢复】
7. 「VOC 回流边界」：VOC 只产出证据包，不替代立项决策；服务指标改善但品牌指标恶化的冲突信号触发 AGT-005 复核而非归因本 Case。【显·SCN-015 §范围外/验收】
8. 「平台规则版本化」约束：Amazon 评价政策、消息系统规则、各渠道客服规范以官方规则版本引用；违规后果分级；规则版本不明即冻结。【显·SCN-015 §输入/冻结条件】

## 类4 · 控制规则（第 12–16 句）

12. 触发建单评估的信号：工单 SLA 周期、评价监控日更、退货周/月复盘、VOC 月度回流；客诉聚类（同 SKU/同原因集中）、评价评分骤降、新品退货率异常、CSAT 下滑、平台账号健康预警（OAR/VC 趋势）、负面评价扩散；结构触发=服务问题占比上升但产品指标正常。【显·SCN-015 §触发】
13. 冻结条件：PII 访问范围未在 Charter 声明；平台消息/评价规则版本不明；退款/补偿权限上限未定义；客诉聚类指向质量事件但 FLOW-07 Case 未建立；输入超出渠道授权范围。【显·SCN-015 §授权与例外】
14. 「红线三禁」（任何授权下不执行）：Amazon 买家站外联系（平台规则禁止+无身份可触达，只能走平台消息系统）；评价激励/筛选/代写（平台明令禁止）；健康相邻信息用于营销画像。【显·SCN-015 §授权与例外】
15. 高风险动作分级：退款/补偿超 Charter 阈值【数】、涉及法律/合规承诺的回复、批量评价回复——逐对象单独审批；**评价回复发布后不可撤回**，故评价类动作实行发布前强制复核而非事后补救。【显·SCN-015 §授权与例外/接管与恢复】
16. 禁止：直接对客户发消息、退款、发退货标签（当前无授权，全部 `NoActionRecord` 或 Action Intent）；不做重大质量/账号事件处置（归 FLOW-07）；不做产品功能定义（VOC 只产证据包）。【显·SCN-015 §范围外/STG-07】

## 类7 · 查询与校验（第 25–29 句）

17. 「服务指标四维」查询：首响/解决时长、CSAT、退货率与退货原因结构、评价评分与响应率、VOC→产品反馈周期、服务动作回执完整率——按渠道×SKU 聚合，跨渠道不混算。【显·SCN-015 §验收】
18. 「VOC 证据引用校验」：VOC 摘要每条结论必须带证据引用；少量负面不得写成「产品普遍缺陷」结论；VOC→SCN-002/SCN-009 回流须经 `correlation_id` 关联已验收 Artifact。【显·SCN-015 §验收/必须回放】
19. 「KANO 缺口标注」校验：服务诊断产物须按必备/期望/兴奋属性标注缺口（书2 体验即资产框架）；缺标即退回 STG-04。【显·SCN-015 §业务闭环 STG-04；判定规则 pending_data】
20. 「SCN-015 验收回放」清单（五必测）：①Amazon 买家站外联系请求（红线拦截）；②评价激励话术（平台规则拦截）；③超权限退款（Policy Gate 拦截）；④VOC 少量负面被夸大为普遍缺陷（证据引用检查拦截）；⑤跨渠道退货率被直接平均（口径规则拦截）。【显·SCN-015 §必须回放】
