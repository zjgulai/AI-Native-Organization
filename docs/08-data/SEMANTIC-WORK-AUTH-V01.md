## 分类规则

| 层 | 判据 | 典型工作 |
|---|---|---|
| **A 层 · 自动** | 产物为文档/分析/监控/草稿/计划/台账，无外部副作用 | 巡检、周报、方案、清单、评估、核算、草稿 |
| **B 层 · 客户确认** | 工作执行动作本身产生外部副作用：写店、对外触达、资金、账号、实物 | 上架、开店、寄样、应诉、投放执行、退款 |

- **工作名即判据**：含「草稿/方案/清单/计划/评估/核算/监控/巡检/复盘/台账/材料/设计」的产出物型工作归 A；含实际执行外部动作的归 B。
- **项目型工作按终态动作归类**：项目本身若以外部动作收口（如「开店建站」「出海启动」），归 B；以文档/方案收口（如「新品立项」「大促备战」）归 A——其子动作由对应工作项分别授权。
- **11 条跨层引用（ref）不重复计数**：引用工作继承被引工作项的层级。
- **B 层内三级风险档**（对齐 PV-16/17/18 逐对象审批子集）：高=资金/账号/实物/对外正式主张；中=店铺写入/对外一般触达/配置变更；低=草稿态写入等最小副作用。
- **A 层工作可产出 Action Intent**：A 层产物中识别出的执行需求（如结算差异申诉）以 Intent 形式移交，不改变该工作项本身的 A 层属性。

1. **23/117 ≈ 20% 进 B 层**——与「读取+出草稿自动」的产品承诺一致：大部分工作是诊断/方案/监控型，执行型集中在店铺写入、对外触达、资金、账号、实物五类。
2. **边界判断请重点核**：
   - `W-1.3-04` Shopify 商品草稿上新——草稿态店铺写入归 B（低风险）；若产品口径认为「草稿」等同内部产物可降 A，请定夺。
   - `W-4.2-01` 售前咨询有依据答复——按知识库/答复稿归 A；若实际由 Sage 直接回复客户则应改 B。
   - `W-6.3-01` 每月结算对账、`W-6.3-03` 申报资料准备——按诊断/准备归 A；差异申报、税务申报提交动作在本目录无独立工作项，执行面待产品定义。
   - `W-MP2-01` 跨平台库存分配与超卖预警——按预警+建议归 A；若含实际改库存分配规则则应改 B。
   - `W-9.4-01` 老客触达旅程设计（A）vs `W-9.4-02` 老客复购提升（B）——设计与执行分层的样板。
3. **高风险 16 项与 PV-16~18 的映射**：逐对象审批的对象粒度（按店铺/订单/达人/批次）已在 confirm_scope 标注，待与权限四元组逐条对齐。
4. **执行面缺口**：B 层确认的产品形态（客户确认按钮/审批流/批量打包）仍是 PV-21 标注的开放产品决策；本表只定层级与粒度。
