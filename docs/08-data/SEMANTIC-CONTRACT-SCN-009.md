# 语义契约 · SCN-009 商品内容、本地化与上架

状态：**v0.1 基线**（2026-11-24 评审通过）。DESIGN_ONLY，未绑定任何运行时。本契约按[「29 句话」模板](KNOWLEDGE-ELICITATION-29.md)试填 SCN-009 场景事理与口径，覆盖类1/2/4/7（对象属性、分层约束、控制规则、查询模板），共 16 条。依据：就绪度矩阵「优先建模」组；场景规格 [SCN-009](../03-scenarios/SCN-009.md) v1。与运营域对象模型的衔接：本场景的 Listing/商品资料/合规对象已在 O-OPS-02/03/04 与 O-PF-05 中定义，本契约只固定**场景级事理与口径**，不重复对象定义。

来源标注：【显】=显性文档已核实（附出处）；【陈】=用户陈述；【推】=推断待验证；【数】=阈值/口径待企业数据回填（pending_data）。

## 类1 · 对象与属性（第 1–4 句）

1. 「上架与本地化包」是 SCN-009 的最终产物（业务实体），它有：每个 SKU/渠道的 Listing 修改清单（含产品事实锚点、合规自查、本地化版本、预期双层指标）、上架/下架/修改动作序列、依赖与停止条件。【显·SCN-009 §业务闭环 STG-05】
2. 「Listing Evidence Pack」是 STG-04 的证据工件，有：现有内容快照、主数据差异、合规缺口、本地化质量、表现数据、VOC 聚类六类；验收判据为来源齐全率 100%。【显·SCN-009 §业务闭环 STG-04/验收】
3. 「信息准确性问题」四级分级枚举：事实错误/夸大宣称/本地化错误/风格不一致——诊断产物须逐条标注分级，事实错误与夸大宣称为最高优先。【显·SCN-009 §业务闭环 STG-04】
4. 「SCN-009 Case」三流绑定：FLOW-09（品牌资产口径，AGT-029）/FLOW-04（新市场与合规上架，AGT-024）/FLOW-01（当期 GMV）——一张 Case 只绑定一条主价值流（D-025）。【显·SCN-009 §适用说明】

## 类2 · 分层与约束（第 5–8 句）

5. 「商品信息 vs 品牌内容」边界：本场景管「商品卡片说了什么、说得对不对、能不能上架」；品牌故事与活动传播属 SCN-012；产品定义与立项属 SCN-003/004；定价决策属 SCN-010。【显·SCN-009 §适用说明】
6. 「产品事实锚点」约束：每条 Listing 修改须能回溯到版本化产品事实（主数据/O-OPS-02 商品资料事实表）；无法证实的宣称**删除而非弱化**。【显·SCN-009 §授权与例外】
7. 「内容五标准」诊断框架：准确信息/吸睛/场景/易传播/调性一致（书2）；「渠道购买场」=场景+媒体+渠道三位一体——诊断按此框架产出信息资产缺口。【显·SCN-009 §业务闭环 STG-04；书2 ch16/17】
8. 「本地化版本」约束：翻译须有版本与母语级审核标注；本地化不得改变产品事实原意；词库/风格指南版本化引用。【显·SCN-009 §输入/验收】

## 类4 · 控制规则（第 12–16 句）

12. 触发建单评估的信号：新品上市上架、季度 Listing 优化周期、市场/渠道扩展、新品类进入评估；Listing 转化率拐点、信息相关退货/差评聚类、本地化错误投诉、平台政策/合规规则变化、竞品 Listing 重大更新。【显·SCN-009 §触发】
13. 冻结条件：商品主数据缺失或版本冲突、合规规则库未覆盖目标市场、产品事实与 Listing 声明不一致且无法确认、本地化母语审核不可用且影响发布、输入超出 Charter 范围。【显·SCN-009 §授权与例外】
14. 「合规自查全覆盖」规则：上架包中每个 SKU×渠道×语言的合规自查覆盖率必须 100%；合规资质到期未更新即冻结对应分支；Listing 被平台拒审记入 Case Ledger 并触发合规复审。【显·SCN-009 §验收/接管与恢复】
15. 「信息错误双重计价」规则：信息错误导致的退货/差评同时计入品牌资产损伤，不得只看转化指标；夸大宣称类问题在 Assurance 阶段即拦截，不进入执行。【显·SCN-009 §验收】
16. 禁止：直接修改 Listing 或上架商品（当前无授权）；上架与修改只以逐对象 Action Intent 存在（每个 SKU×渠道×语言一个意图）；不做定价决策（SCN-010）、不做广告优化（SCN-011）。【显·SCN-009 §范围外/STG-07】

## 类7 · 查询与校验（第 25–29 句）

17. 「信息资产缺口」查询：按 SKU×渠道×语言 聚合 Listing 现状与内容五标准评分，输出缺口清单；信息准确性问题按四级分级聚合分布。【显·SCN-009 §业务闭环 STG-04；评分规则【推】】
18. 「合规覆盖矩阵」查询：按 市场×品类×资质类型 核对合规规则库覆盖度与资质有效期；未覆盖市场即冻结上架分支（衔接 O-OPS-04 ComplianceRequirement）。【显·SCN-009 §冻结条件；对象衔接【推】】
19. 「上架→转化归因」查询：上架动作回执与转化/退货/差评反馈关联，输出可归因比例与信息相关问题占比；归因窗口【数】。【显·SCN-009 §验收；窗口 pending_data】
20. 「SCN-009 验收回放」清单（五必测）：①Listing 功效宣称无证据支撑被上架（应被 Assurance 拦截）；②本地化翻译改变产品事实原意（应被 AGT-005 拦截）；③合规资质过期后仍上架（应冻结）；④Amazon Listing 被当作可触达用户数据来源（口径违规）；⑤书中内容效果倍数被当作 Momcozy 实测（来源标注违规）。【显·SCN-009 §必须回放】
