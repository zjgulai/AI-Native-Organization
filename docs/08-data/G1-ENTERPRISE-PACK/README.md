# G1 企业交付包（Enterprise Pack）

状态：**v0.1 基线**（2026-11-25 评审通过）。本目录是 [G1 数据需求文档](../G1-DATA-REQUIREMENTS.md) 的**企业侧可填写版本**——把内部规格转写为对方可直接回填的表单与指引。内部规格仍为权威口径；本包与规格冲突时以规格为准并回本目录修订。

**对象**：Momcozy 数据/运营/IT 接口人、财务、合规、品牌负责人。
**回传方式**：直接在各表「回填」列填写（Markdown/打印均可），或按 05 模板逐源打包证据提交。

## 包内文件与使用顺序

| 文件 | 内容 | 谁来填 | 何时要 |
|---|---|---|---|
| `G1P-01-BRIEF.md` | 交付说明：背景、边界、三层验收路径、已知信息预填 | 无需填写，先读 | 第 1 步 |
| `G1P-02-AVAILABILITY-FORM.md` | 数据可得性确认表：五源范围包 + 八组出海新源 + 系统盘点 | 数据/运营/IT 接口人 | 第 2 步 |
| `G1P-03-RULESET-FORM.md` | 客户规则集采集表：10 项阈值与规则（G1C） | 经营层/品牌/合规负责人 | **本周即可启动，无技术依赖** |
| `G1P-04-EXPORT-GUIDE.md` | 数据导出指引：各平台报表位置、粒度、时窗、注意事项 | 执行导出的运营/IT | 与 02 同步使用 |
| `G1P-05-EVIDENCE-TEMPLATE.md` | 证据包提交模板：每源六要件 + 字段字典 + 快照元数据 | 导出执行人 | 首份样例提交时 |

## 边界声明

本包不索取：任何系统账号密码/API Token、客户或买家个人信息明细、生产系统写入权限。数据以**脱敏导出快照**交付；原始文件留企业侧受控位置，我方只接收脱敏样例+字段字典+快照哈希。
