# G1P-05 证据包提交模板

版本：v0.1 基线（2026-11-25 评审通过）。每个数据源提交**一份证据包**；FLOW-09 五源（Part A）按六要件执行，出海产品层新源（Part B）按六要件的宽松版执行（要件⑥改为口径说明）。复制本模板逐源填写。

## 提交信息（每源一份）

| 项 | 填写 |
|---|---|
| 源名称 / 范围包 | 例：Shopify DTC / `FLOW09_DTC_ANALYTICS_V1`；新源写「出海层-B1 结算财务」 |
| 提交日期 / 提交人 | |
| 对应 G1P-02 行号 | 例：A1-1~A1-8；B1-1~B1-8 |
| 文件命名 | `G1_<源简称>_YYYYMM_<序号>` |

| # | 要件 | 内容 | 是否完成 | 附件/位置 |
|---|---|---|---|---|
| 1 | 脱敏报表样例 + 字段字典 | 首份导出样例（已去 PII）+ 下方字段字典表 | ☐ | |

| 3 | 字段→数据集映射 + PII 排除声明 | 报表字段对应到需求数据项；声明导出环节已排除客户/买家级字段 | ☐ | |

## PII 排除声明（要件③必填）

- 本快照导出环节已排除以下字段：客户/买家邮箱、姓名、电话、地址、订单号明细（对账用途除外且限对账）、买家 ID、评论用户 handle、私信内容。
- 如样例中出现疑似个人信息，请标注并说明处理方式（删除/聚合/保留理由）。

## 提交后流程

1. 我方收到后核对六要件 → 通过则该源进入分层验收（G1A/G1B），未通过项列明补件要求。
2. 验收通过后按约定频率（建议周/月）提供同口径快照；快照元数据随文件一并提交。
3. 权限/规则类变更（如新增 API 接入需求）另走评估流程，不在本模板范围。
