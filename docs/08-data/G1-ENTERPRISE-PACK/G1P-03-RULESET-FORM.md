# G1P-03 客户规则集采集表（G1C）

版本：v0.1 基线（2026-11-25 评审通过）。**本表无需任何数据样例**，纯书面确认即可；是三层交付中启动成本最低的一项，建议本周完成。

**用途**：以下 10 项阈值/规则决定「AI 在什么边界内可自主建议、什么必须升级人工确认」。规则到位后回填权限层与场景契约中的【数】位；未到位的项对应动作一律按「必须人工确认」处理（保守默认，不会放权）。

**填写方式**：每项给出规则值/公式/规则描述 + 适用范围 + 例外 + 确认人 + 日期。拿不准的项可写「待定」并注明需要谁决策——待定项按保守默认执行。
