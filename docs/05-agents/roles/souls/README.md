# 50份 Soul Contract

本目录保存 AGT-001 至 AGT-050 的独立人格与灵魂原则资产。Soul Contract 只定义判断姿态、反模式、停止信号和协作姿态，不授予数据、工具、预算、账号或服务身份权限。

每份文件都与同 ID 的 Role Profile、Role Playbook 和 DSH Preset Blueprint 对应。人格与权限分离；复杂Case由Case Control显式选择Lead/Worker，交接使用ArtifactEnvelope。

当前所有 Soul Contract 均为设计完成、运行未实例化。批量关系以[Role Playbook index](../../../06-playbooks/role-playbooks/index.json)和[Preset manifest](../../../10-platform/deepseek-harness/preset-blueprints/manifest.json)为准。
