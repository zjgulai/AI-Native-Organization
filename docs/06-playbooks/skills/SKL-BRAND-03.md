# SKL-BRAND-03：出海市场进入检查

状态：v1 设计契约。候选维护：AGT-048。知识来源：[品牌增长方法论](../BRAND-GROWTH-METHODOLOGY.md) §4「出海」、书2 第 23 章（成熟/成长/新兴三类品牌、六条经验）。

## 职责

在进入一个海外市场/渠道前，判定品牌在该市场的类型路径，并按六条经验生成进入检查清单。回答的问题是：**这个市场我们以什么身份进去、靠什么打法、哪些前置条件不满足就不该进。**

## 输入合同

- 目标市场（国家/地区/平台）与品类；
- 品牌现状：在该市场的认知/销售基础（若有）、全球其他市场的打法与结果；
- 竞争格局初扫：本土巨头与全球巨头名单、品类格局；
- 资源约束：预算量级、本地化团队现状、合作伙伴候选；
- Momcozy 适用前提：Born Global 新兴品牌偏「成长品牌」路径（待逐市场验证，不预设）。

## 产物 schema（最低字段）

`market_entry_check`：

- `brand_type_judgment`：成熟 / 成长 / 新兴 三类判定及依据（出海时长、本土认知、渠道份额与心智份额的匹配度）；
- `six_point_checklist[]`：六条经验逐项——品牌建设思维（渠道≠心智）、目标市场消费者洞察、本土巨头对标、合作共赢路径、本地化团队、敢为人先窗口期；每项标注 具备/缺口/需验证；
- `entry_mode_candidates[]`：子品类精准对标 / 细分心智突破 / 渠道卡位 等路径候选，各附前置条件；
- `dual_kpi_setup`：该市场须分别建立的渠道层指标（销量/份额）与心智层指标（认知/声量/偏好）口径建议；
- `data_asset_plan`：该市场可分析/可触达数据的预期来源与缺口（对接 SKL-BRAND-01 数据资产卡）；
- `go_no_go_gates[]`：进入前必须满足的硬门槛（洞察完成度、本地化能力、合规）；
- `evidence_grade` 与 `uncertainties[]`。

## 质量门禁

- 「渠道已上架」不得被表述为「已出海」——心智占有与渠道占有必须分列结论；
- 六条经验逐项必须有证据或显式「待验证」，不允许整体打勾；
- 对标巨头必须点名具体品牌与品类，不得写「对标国际大牌」；
- 本地化团队项：若无本地成员，必须标注为缺口并给出替代路径（合作方/服务商），不得默认总部外派可行；
- 窗口期判断必须给出时间依据（竞品格局、平台政策、季节性），不得只写「趁早」。

## 工具依赖（候选）

市场公开数据、平台类目数据、社媒监听、竞品监控、AGT-045 指标字典。未接入项记 `tool_gap`。

## 使用岗位与场景

AGT-029（主责判断）、AGT-033（译境/本地化执行视角）、AGT-023（独立站/DTC）、AGT-007（竞争格局证据）。挂载场景：SCN-002（机会判断）、FLOW-04 新市场进入的前置分析、SCN-004 类市场准入评估。

## 边界

不做进入决策本身（决策属 AGT-029/经营层）；不输出具体投放/选品执行方案；不替代合规与法务审查；书中六条经验为方向框架，具体市场结论必须有本地证据。

## 评估案例

待首批 Case 回放回填。回放要点：类型判定是否被后续实际表现验证；六条清单的缺口项是否在进入后真的爆发；双 KPI 是否被实际建账。
