# SKL-BRAND-02：品效归因实验设计

状态：v1 设计契约。候选维护：AGT-048。知识来源：[品牌增长方法论](../BRAND-GROWTH-METHODOLOGY.md) §3（度量）与 §4「量化投资/品效合一」、书2 第 19/20/21/25 章（评估、量化、品效冰山、归因方法）。

## 职责

为品牌域投放与内容实验选择合适的归因/测量方法（AB 测试、多触点归因 MTA、营销组合模型 MMM），并强制产出**归因局限声明**。回答的问题是：**这次投入里，多少能归到即时转化，多少应记为品牌资产的长周期贡献——以及我们凭什么这么分。**

## 输入合同

- 实验/投放范围：渠道、时段、人群、预算量级；
- 可得数据：可回传触点、曝光/点击/转化日志、品牌资产指标现状；
- 时间尺度要求：当期 GMV 核算 vs 长周期资产归因（必填，二选一或双轨）；
- 历史归因产物与已知偏差记录；GMV 护栏阈值（引用 AGT-045/PB-009 口径）。

## 产物 schema（最低字段）

`attribution_design`：

- `method_choice`：AB / MTA / MMM / 组合，及选择理由（数据可得性、触点可回传性、时间尺度）；
- `design_spec`：分组/触点匹配/回归设定、样本量或时间窗、对照方式；
- `horizon_split`：海面上指标（点击/流量/转化，当期）与海面下指标（认知/考虑度/满意度，长周期）的分别核算口径；
- `limitation_statement`（必填）：覆盖四大「占便宜」问题自查——数据可回传偏差、流量规模偏差、品牌周期被效果周期抹杀、作弊/虚假归因；每条写明本设计的残余风险与缓解；
- `guardrail`：GMV 护栏口径与触发复核条件；
- `decision_rule`：何种结果支持继续/调整/停止，区分统计显著与业务显著；
- `evidence_grade` 与 `uncertainties[]`。

## 质量门禁

- `limitation_statement` 缺失或仅写套话 → Assurance 直接退回；
- 品牌类投放不得以单一即时 ROI 作唯一裁决；输出必须同时给出长周期观察窗口建议；
- MTA/AB 结论必须标注触点覆盖率；覆盖率低时结论降级为「方向性参考」；
- MMM 仅在触点数据不可得或线下占比高时推荐，并注明其对长周期品牌因子的处理局限；
- 所有量化预测标注假设条件；禁止把归因结果表述为因果证明。

## 工具依赖（候选）

广告平台归因报表、品牌调研/品牌指标数据源、实验分流能力、AGT-045 指标字典、AGT-035 实验框架。未接入项记 `tool_gap`。

## 使用岗位与场景

AGT-035（主责实验设计）、AGT-032（投放意图的归因字段）、AGT-045（口径）、AGT-029（品牌侧指标定义）、AGT-005（复核局限声明真实性）。挂载场景：SCN-011、SCN-012、SCN-013。

## 边界

不执行投放、不改预算；只产出设计与判定规则；不把平台归因单值当结论；归因模型局限必须随产物流转，供下游复盘引用。

## 评估案例

待首批 Case 回放回填。回放要点：局限声明是否被复核采信；长周期指标是否真的被排入观察窗口；被判「无效」的品牌投放是否存在误杀案例。
