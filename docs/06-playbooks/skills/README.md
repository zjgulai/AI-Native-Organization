## 共用规则

- 每份契约的「产物 schema」是 Stage Artifact 的最低字段要求；实际产物仍须通过所属场景的 Acceptance Gate。
- Skill 产物一律标注证据来源等级：实测数据 / 书中报告口径 / 假设待验证；禁止把书中量化倍数写成 Momcozy 实测。
- Skill 不产生资产动作；需要外发、投放、上架等动作时只输出 Action Intent 供 Policy Gate 裁决。
- 评估案例栏目前均为「待首批 Case 回放后回填」；首个真实 Case 关闭后由 AGT-005 组织回放并更新本目录。
