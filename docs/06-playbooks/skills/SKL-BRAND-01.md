# SKL-BRAND-01：品牌覆盖审计

状态：v1 设计契约。候选维护：AGT-048。知识来源：[品牌增长方法论](../BRAND-GROWTH-METHODOLOGY.md) §2.4（三位一体高覆盖）、§4 渠道购买场与数据资产、书2 第 9/17/24 章。

## 职责

按「场景 × 媒体 × 渠道」三位一体框架，诊断品牌在目标市场的覆盖结构，识别覆盖缺口，并把每个渠道的数据资产按「可分析 / 可触达」两级建档。回答的问题是：**钱和内容花在哪些场景、触达哪些媒体、落在哪些渠道，以及哪里是结构性空白。**

## 输入合同

- 目标市场与品类范围、时间窗（必填）；
- 渠道清单及各渠道数据可用性声明（Amazon/独立站/社媒/线下，须注明可分析级与可触达级）；
- 品类渗透率与品牌渗透率的现有口径（缺则标注缺口，不估算）；
- 媒体投放与内容分发记录（有则引用版本，无则记缺口）；
- 历史覆盖审计产物（跨 Case 只读引用已验收 Artifact）。

## 产物 schema（最低字段）

`coverage_audit_report`：

- `scope`：市场/品类/时间窗/渠道集合；
- `three_dim_grid`：场景×媒体×渠道覆盖矩阵，每格标注 覆盖/缺失/未知 及证据引用；
- `penetration_split`：品类渗透率、品牌渗透率、推导的相对份额（仅当输入口径齐备时计算，否则标注不可算）；
- `sov_snapshot`：各媒体/渠道声量份额现状与口径局限；
- `data_asset_cards[]`：每渠道一张卡——可分析级（无/部分/完整）、可触达级（无/部分/完整）、代理信号清单、已知偏差；
- `gap_findings[]`：覆盖缺口，每条含 证据 / 影响面 / 建议验证场景；
- `evidence_grade`：实测 / 书中报告 / 假设 三级标注；`uncertainties[]`。

## 质量门禁

- 矩阵每格必须有证据引用或显式「未知」；禁止无证据填「覆盖」；
- 「可触达」判定必须区分平台数据可下载与品牌可主动触达（如 Amazon 评论可读但买家身份不可触达）；
- 渗透率公式只在输入口径一致时使用；口径不一致时输出分列值而非合成值；
- 发现的缺口必须可映射到具体场景（SCN-009/011/012/013）供下游 Case 消费。

## 工具依赖（候选，未核实接入状态）

渠道经营报表导出、广告平台报表、社媒监听数据、独立站分析、AGT-045 指标字典。未接入项在产物中记 `tool_gap`，不阻塞产出但降低证据等级。

## 使用岗位与场景

AGT-029（主诊断）、AGT-045（口径校验）、AGT-006/007（证据供给）。挂载场景：SCN-002（机会判断输入）、SCN-009/013（渠道体验诊断前置）。

## 边界

只读分析；不输出投放/内容/商品动作建议的执行细节（只给验证方向）；不把单次快照当趋势；不替代 AGT-045 的口径仲裁。

## 评估案例

待首批 Case 回放回填。回放要点：矩阵空白格是否被如实标注；可触达判定是否被 Amazon 数据现实纠正；缺口结论是否被下游 Case 实际采用。
