# Playbook

状态：[8份场景Playbook候选稿](PLAYBOOKS.md)已完成，覆盖触发、输入、步骤、交接、例外、恢复和验收。具体系统、额度及责任人落实后再形成可执行版本。

使用 [Playbook 模板](../../templates/playbook.md)，将岗位知识落实为触发条件、输入质量检查、判断步骤、标准产物、授权动作、异常升级与经营反馈。

同一个岗位可以参与多个场景；同一份通用 Playbook 可以有经过批准的市场或渠道差异规则。复用边界需要通过实例检验，不将全部经验塞进一个总提示词。

每份 Playbook 需能回答“什么时候做、凭什么判断、做成什么、谁能决定、出错怎么办、怎样证明有效”。
