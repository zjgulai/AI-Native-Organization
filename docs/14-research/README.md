# 调研与来源

用途：核实平台、渠道、组织方法和实现约束，为讨论提供证据，不替代用户的经营决定。

已完成[五个指定项目的源码与适配评估](REFERENCE-EVALUATION.md)和[企业组织材料评估](../01-discovery/ORGANIZATION-ASSESSMENT.md)。公开项目按固定源码快照记录，企业材料只保留部门与聚合摘要。

优先读取当前产品的官方文档、第一方代码和企业授权提供的资料。法规、平台政策、接口权限、产品版本和定价等易变化信息，在使用时重新核实。

所有使用的外部资料登记在 [SOURCES.md](SOURCES.md)，注明来源、日期、版本、支持的结论与适用限制。企业原始业务数据和私密会话不直接进入此目录。
