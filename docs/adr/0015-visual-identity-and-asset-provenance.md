# ADR-0015：视觉身份与素材来源独立于角色运行契约

状态：已确认的设计决定。日期：2026-09-23。

适用范围：Sanbao_Web 图像在本项目中的来源治理、展示投影、3+50数字分身视觉身份和未来候选素材池。

关联决定：D-053、D-065、D-067、D-068；关联方案：[Sanbao视觉身份与资产方案](../12-rollout/SANBAO-VISUAL-IDENTITY-ASSET-PLAN.md)。

## 背景

D-053已经将50个执行岗位定义为可独立寻址的数字分身，且每个岗位由Soul Contract、Role Playbook、Preset Blueprint、Skills、产物、评估和Access边界共同定义。D-065进一步定义3个管理层岗位为决策权平面。用户随后要求把 Sanbao_Web 中的图像完整融入3+50数字分身，并保留未使用图像供未来新数字员工使用。

Sanbao_Web 的数字员工图像具有独立人物ID、深浅主题、尺寸变体、来源图和生成资料。若把它们写入角色目录、Soul、Playbook、Preset或Role Release Bundle，会把展示资料混入运行身份，触发无关的50岗位资产重建，并产生“换头像即改变权限或角色人格”的错误语义。原始来源、参考图和生成资料也不应进入公开页面或默认模型上下文。

## 决策

1. 采用独立的 Visual Identity Release 管理头像、主题、尺寸、alt text、来源、哈希、许可状态、可见范围、主视觉绑定与候选素材池。
2. Role Release Bundle 与 Visual Identity Release 是两条相互引用但不互相替代的版本线。前者管理角色运行合同；后者只管理展示和来源追溯。
3. 上游 Sanbao_Web 是视觉素材的待冻结事实来源。执行前必须在VIS-G0固定具体Git提交或Release、路径与哈希；不得以漂移分支作为可发布来源。
4. AGT-001至AGT-050以同ID源人物作为映射基线。MGT-001天時、MGT-002地利、MGT-003人和采用候选短名单后由用户人工确认的绑定流程。AGT-051和AGT-052保留源语义；未选素材进入候选池，不自动创建岗位。
5. 展示层只可使用经批准、尺寸受控的交付图。sources、references、生成提示词、设计输入和未批准候选素材默认受限，不进入公开页面、dist或默认模型上下文。
6. 视觉资料不能决定角色职责、Soul、Skills、Access、MDC/GOC、Service Identity、Case编排、Action Intent、权限、预算、运行状态或生产授权。

## 选择理由

- 独立版本线保留图像的来源和发布责任，同时不污染既有五/六类契约、Role Release Bundle和preset生成流程。
- 同ID映射使50个执行岗位可用可审计事实完成稳定绑定，而不是靠主观外貌重配岗位。
- 管理层主视觉由用户最终确认，避免系统擅自把某张脸赋予CEO、增长或治理含义。
- 受限来源资料与公开交付图分层，降低参考图、提示词和来源未核验信息被意外发布的风险。
- 候选池保留未来扩展能力，但不把静态素材数量误当作已启用的数字员工数量或并发运行能力。

## 弃选方案

- 将头像字段直接写入角色目录、管理目录、Soul、Playbook、Preset或Role Release Bundle：弃选。它会把展示信息混入运行合同，并可能触发无关资产重建或错误的权限语义。
- 每次新建角色都重新生成或重绘人物，不保留来源人物：弃选。它破坏可追溯性、复用和视觉连续性。
- 将全量原图、参考图和提示词直接放入公开站点：弃选。来源和公开范围尚未核验，且受限资料并非普通展示资产。
- 把候选人物预登记为运行数字员工：弃选。它会把当前3+50范围错误扩大为素材人物数量。

## 影响与后续

- 新增的机器可读台账必须独立于角色运行资产，仅供Site或展示层读取。
- 仅更换头像、主题、尺寸、裁切或alt text不会产生新的Role Release Bundle；改变角色使命、人格、技能、权限或边界仍必须走既有角色契约与Bundle门禁。
- VIS-G0至VIS-G6定义来源冻结、权利分级、映射、画像投影、质量检查和页面接入的顺序；在相应门禁前不得声称素材已导入、公开或运行。
- 本ADR不授权复制图片、创建上游Release、改动页面、接入DSH、连接企业系统或执行任何生产动作。

## 验证

1. 角色目录、Soul、Playbook、Preset、管理目录和现有Role Release Bundle输入中不得新增视觉运行字段。
2. 视觉资产计划和台账必须可区分Source Asset、Derived Rendition、Visual Identity Binding、Candidate Asset Pool和Visual Identity Release。
3. 未来静态检查必须断言3个MGT加50个AGT为53个视觉画像范围，候选池不计为运行岗位。
4. 公开构建物不得包含来源图、参考图、生成提示词或未批准候选素材。
