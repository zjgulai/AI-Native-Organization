# SCN-017：现金、汇率与资金安排

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-08（经营复盘、资源和组织能力更新）绑定时为 AGT-001 衡远；FLOW-03（供需）绑定时为 AGT-016 知量。依据：D-025、D-078、PB-008。

适用说明：本场景是企业的**资金生命线**——现金流预测、汇率风险管理、资金安排（付款/回款/融资/备付）。FLOW-08 绑定时 AGT-001 衡远对「资源与资金版本变更」负责；采购/履约侧的资金占用影响经 `correlation_id` 关联 FLOW-03 Case。设计红线：**AI 只预测、预警与建议，不执行任何资金动作**——付款、融资、外汇交易全部是高风险 Action Intent，须经 Policy Gate 与人工审批。

## 经营目的与范围

把现金、汇率与资金安排转化为**可预测、可预警、可审批的资金管理闭环**，让「钱够不够、什么时候要、汇率风险多大」有据可查。

- 业务对象：现金流预测（回款/付款/费用/税费）、汇率敞口（收入/成本/库存币种错配）、资金安排（付款计划、回款跟踪、融资需求、备付金）、外汇风险管理（对冲/锁汇/自然对冲）；不含预算分配决策（SCN-001）、结算对账（SCN-016——本场景消费其财务事实）、采购付款执行（SCN-006/016）。
- 范围内：现金流信号监测 → 预测更新 → 风险识别（流动性/汇率/集中度）→ 资金安排建议 → Action Intent（付款计划/融资申请/对冲指令）→ 执行回执核验 → 偏差复盘。
- 范围外：不直接执行付款/融资/外汇交易（当前无授权，全部 `NoActionRecord` 或 Action Intent）；不做预算分配（SCN-001）；不做结算对账（SCN-016）；不做税务申报（AGT-042）。
- 不适用：无现金流数据基线（先建数据接入再谈预测）；单一币种无汇率敞口（降级为现金流管理）；资金安排已由银行自动化覆盖（标注 `automated` 降低人工介入）。

## 触发与输入

### 触发

- 经营节奏：周度现金流预测、月度资金安排、季度汇率风险评估、年度融资规划、重大事件后应急重估。
- 信号触发：现金余额低于安全线、回款延迟、付款高峰叠加、汇率波动超阈值、融资到期、大客户回款风险、供应商要求缩短账期。
- 结构触发：收入与成本币种错配扩大、现金流季节性波动加剧、多渠道回款周期不一致、外部环境变化（利率/汇率/贸易政策）。

## 业务闭环

1. **STG-01 信号接收**：现金余额、应收应付、回款进度、汇率波动、融资到期分别建档。
2. **STG-02 建单**：Case Charter 固定主价值流（FLOW-08 为主，FLOW-03 关联不兼）、主场景 SCN-017、范围（币种/期间/资金池/风险类型）、资金动作权限上限声明。
3. **STG-03 上下文装配**：固定对应岗位 Release Bundle；装载现金流预测与资金安排 Skills；只读银行/结算/业务/汇率工具；融资与授信版本库。
4. **STG-04 证据与诊断**：AGT-041 组织 Cash Evidence Pack（银行流水、应收应付、回款计划、付款计划、汇率敞口、融资结构）；诊断输出流动性预测（现金余额轨迹）、汇率风险敞口（币种×金额×时间）、资金缺口/盈余预测、集中度风险；区分「已知现金流」（合同/订单）与「预测现金流」（业务预测）。
5. **STG-05 方案产物**：「资金行动包」——付款计划优化建议、回款催收建议、融资需求建议（额度/期限/成本）、汇率风险对冲建议（自然对冲/远期/期权）、备付金调整建议；每条标注风险等级与可证伪条件。
6. **STG-06 Assurance 门禁**：确定性校验（币种一致、银行锚定、融资额度约束、schema、现金流守恒）+ AGT-005 语义复核（预测是否过度乐观、敞口是否遗漏、对冲建议是否匹配风险等级、融资建议是否有授信依据）。
7. **STG-07 受控动作**：获批方案拆为 Action Intent——付款计划调整、融资申请、对冲指令、备付金调整；当前阶段全部 `NoActionRecord` 或内部审批 Intent。
8. **STG-08 核验与关闭**：资金动作回执与现金余额核验；预测准确率回流；汇率风险复盘；关闭后学习提取回流（哪些预测偏差大、哪些风险高频、哪些对冲有效）。

## 授权与例外

- **允许**：只读银行/结算/业务/汇率数据；产出预测、风险诊断、资金建议、Action Intent 与约束校验；跨 Case 引用已验收 Artifact。
- **冻结条件**：银行流水数据不可用；应收应付口径不一致；汇率数据源不可靠；融资授信信息过期；现金流预测与业务预测严重背离。
- **高风险动作分级**：融资申请（涉及授信）、外汇对冲（涉及金融衍生品）、大额付款计划变更、备付金大幅调整——逐对象单独审批；AI 不得执行任何资金动作只建议。
- **歧义处理**：现金流预测不确定时给区间并标注 `forecast_uncertain`；汇率敞口无法量化时标 `fx_unquantified` 并扩大证据范围。
- **重复与部分失败**：同一期间跨 Case 重复预测时关联既有 Case 更新；部分数据源缺失时只冻结受影响币种/期间；Worker 产物不合格退回 STG-04。

## 接管与恢复

- 停止条件：连续两轮补证不满足最小输入；发现现金流预测系统性偏差；银行授信变更；汇率剧烈波动超历史极值；融资到期无法续作。
- 冻结范围：仅冻结受影响币种/期间/资金池；已执行的资金动作由执行 Case 管理，本 Case 只引用回执。
- 已产生外部效果：付款计划调整、融资、对冲——需回执可对账；融资被拒或对冲亏损的标 `financial_loss` 进入复盘。
- 恢复：冻结解除后从断点继续；Cash Evidence Pack 版本化保留；汇率/授信/法规版本更新后既有建议标记 `needs_revalidation`。

## 验收与经济性

- **产物验收**：Evidence Pack 四源齐全率 100%；现金流预测有银行锚定且给区间；汇率敞口覆盖全部币种；每个资金建议有风险等级与约束校验；融资建议有授信依据。
- **经营指标**：现金流预测准确率、流动性覆盖率、汇率风险敞口、融资成本、备付金充足率、资金缺口发生率、对冲有效性。
- **双层 KPI 关系**：本场景是**生存底线**——现金断裂则所有经营指标归零；资金效率影响 GMV 可持续性（FLOW-01 关联）与品牌长期投入能力（FLOW-09 关联）；本 Case 不背经营结果只对资金事实与风险负责。
- **经济性门槛**：首个周期以「现金流预测与银行实际偏差可测 + 至少一次资金建议被采纳 + 汇率敞口报告完整」为验收前提。
- **必须回放**：现金流预测无银行锚定（应被锚定规则拦截）；汇率敞口遗漏币种（应被覆盖率检查拦截）；融资建议无授信依据（应被约束校验拦截）；对冲建议与风险等级不匹配（应被风险校验拦截）；AI 执行资金动作越权（应被授权边界拦截）。
