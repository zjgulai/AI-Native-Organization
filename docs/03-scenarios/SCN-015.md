# SCN-015：客服、退换货、评价与客诉

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-05（客户旅程）绑定时为 AGT-034 续缘；FLOW-07（重大质量/账号事件）绑定时为 AGT-018 质守。依据：D-078、D-025、D-026、PB-005、PB-007、[品牌增长方法论](../06-playbooks/BRAND-GROWTH-METHODOLOGY.md) 第 4 节「体验」「数据资产」、[FLOW-09 双层 KPI 字典](../08-data/FLOW-09-DUAL-KPI-CATALOG.md)。

适用说明：本场景是**双流绑定**的典型——常规服务闭环归 FLOW-05/AGT-034；一旦客诉聚类指向质量缺陷或账号风险，按 D-025 拆为 `correlation_id` 关联的 FLOW-07 Case（确定性规则命中且唯一绑定时可由 D-026 Emergency Guard 建单）。同时它是全场景中 **PII 最密集**者（客户身份、订单、健康相邻信息），也是 VOC 反哺产品与洞察的枢纽——评价与客诉不是成本中心，而是 SCN-002/SCN-009 的上游证据源。

## 经营目的与范围

把客户问题解决转化为**可追溯、可复核、可反哺的服务闭环**，并把评价/客诉信号结构化回流产品与运营。

- 业务对象：售前咨询（AGT-036 安心）、售后工单与客诉（AGT-037 解忧）、退换货与逆向物流（AGT-020 行舟）、平台评价（Amazon/DTC/社媒）、会员社区反馈（AGT-039 同行）；不含营销触达活动（SCN-012/013）、定价争议（SCN-010）、库存补货决策（FLOW-03）。
- 范围内：工单分诊 → 方案建议 → 逐对象动作（回复/退款/退货标签/评价回复）→ 回执核验 → VOC 结构化回流；退货原因分析与处置建议。
- 范围外：不直接对客户发消息、退款、发退货标签（当前无授权，全部 `NoActionRecord` 或 Action Intent）；不做重大质量/账号事件处置（归 FLOW-07 Case）；不做产品功能定义（VOC 只产出证据包，不替代立项决策）。
- 不适用：无工单系统基线的新渠道（先建档再谈自动化）；平台禁止站外联系的渠道中试图绕过平台消息系统（见「授权与例外」红线）。

## 触发与输入

### 触发

- 经营节奏：工单 SLA 周期、评价监控日更、退货周/月复盘、VOC 月度回流。
- 信号触发：客诉聚类（同 SKU/同原因集中出现）、评价评分骤降、新品退货率异常、CSAT 下滑、平台账号健康预警（OAR/VC 趋势）、负面评价扩散信号。
- 结构触发：服务问题占比上升但产品指标正常（期望管理问题而非质量问题）、跨渠道口径冲突（同产品不同渠道退货政策解释不一致）。

## 责任与参与者

- **AI 结果负责人**：FLOW-05 绑定时 AGT-034 续缘（对「问题解决与复购改善」负责）；FLOW-07 绑定时 AGT-018 质守（对「事件处置与恢复证据」负责）。两层结果不得由同一 Case 兼负。
- **业务贡献**：AGT-036 安心（售前咨询与购买指导）、AGT-037 解忧（售后客诉与服务补救）、AGT-038 回声（体验洞察与 VOC 结构化）、AGT-039 同行（用户教育与社区反馈）、AGT-020 行舟（退货处置与逆向成本）、AGT-044 安界（产品合规与隐私边界）、AGT-050 门卫（数据访问权限）、AGT-006/007 观潮/察微（VOC 证据供给）。
- **编排**：AGT-002 / 模型外 Case Control。
- **独立复核**：AGT-005——检查回复是否真正解决问题、退款/补偿是否越权、VOC 回流是否夸大、PII 是否越界。
- **外部执行主体**：各渠道消息系统与后台——当前未授权连接；客户触达、退款、退货标签、评价回复只以 Action Intent 存在。

## 业务闭环

1. **STG-01 信号接收**：工单/评价/退货/客诉按渠道×SKU 聚合；服务信号与质量信号分流建档（后者标记 `flow07_candidate`）。
2. **STG-02 建单**：Case Charter 固定主价值流（FLOW-05 或 FLOW-07，不可兼）、主场景 SCN-015、范围（渠道/SKU/工单类型/时间窗）、**PII 访问范围声明**与客户触达边界声明。
3. **STG-03 上下文装配**：固定对应岗位 Release Bundle；装载服务诊断与 VOC 技能（SKL-BRAND-04 可用于客诉聚类）；只读工单/订单/评价工具限定在 PII 范围内；品牌调性与服务话术规范版本。
4. **STG-04 证据与诊断**：服务岗位产出 Service Evidence Pack（工单分类、退货原因、评价主题、解决时长、补偿记录）；结果负责人形成 Diagnosis Record——区分「服务问题」（可回复解决）、「产品问题」（回流 SCN-009/002）、「期望问题」（回流 SCN-012 内容/说明）、「质量事件」（升级 FLOW-07）；KANO 视角标注必备/期望/兴奋属性缺口。
5. **STG-05 方案产物**：「服务行动包」——逐工单回复草稿、退款/换货/补偿建议（含金额与依据）、退货处置建议、评价回复草稿（合规检查后）、VOC 结构化摘要（主题×证据引用）；每条标注可证伪条件与所需授权级别。
6. **STG-06 Assurance 门禁**：确定性校验（PII 字段范围、平台消息规则、退款上限、话术规范、schema）+ AGT-005 语义复核（方案是否对症、补偿是否合理、VOC 结论是否有证据支撑、健康相邻内容是否被不当使用）。
7. **STG-07 受控动作**：获批方案拆为逐对象 Action Intent → Policy Gate 判定 → Execution Broker 执行 → 逐对象回执（回复已发送/退款已执行/标签已创建/评价回复已发布）；拒绝/异常记入 Case Ledger。当前阶段无授权连接时全部 `NoActionRecord`。
8. **STG-08 核验与关闭**：回执与解决核验（首响/解决时长/客户确认）；VOC 摘要移交关联 SCN-002/SCN-009 Case；服务指标复盘（CSAT/OAR/退货率/评价趋势）；关闭后学习提取回流。

## 授权与例外

- **允许**：范围内只读工单/订单/评价数据；产出诊断、回复草稿、行动建议与 Action Intent；跨 Case 引用已验收 Artifact。
- **冻结条件**：PII 访问范围未在 Charter 声明；平台消息/评价规则版本不明；退款/补偿权限上限未定义；客诉聚类指向质量事件但 FLOW-07 Case 未建立；输入超出渠道授权范围。
- **红线（任何授权下不执行）**：**Amazon 买家站外联系**（违反平台规则且无身份可触达，Amazon 客服只能走平台消息系统）；**评价激励/筛选/代写**（平台明令禁止）；健康相邻信息用于营销画像；PII 导出至聚合分析层。
- **高风险动作分级**：退款/补偿超 Charter 阈值、涉及法律/合规承诺的回复、批量评价回复——逐对象单独审批。
- **重复与部分失败**：同 `case_dedupe_key` 关联既有 Case；部分渠道数据缺失时只冻结受影响渠道分支；Worker 产物不合格退回 STG-04。

## 接管与恢复

- 停止条件：连续两轮补证不满足最小输入；发现 PII 越界访问；平台发出客服绩效或合规警告；工单积压超 SLA 且无降级方案。
- 冻结范围：仅冻结受影响渠道/SKU/工单类型；已执行的 Action Intent 由执行方 Recovery Contract 负责（回复撤回不可行的记 `sent_unrecoverable`，退款冲正走原路），本 Case 只引用回执。
- 已产生外部效果：已发送回复、已退款、已发布评价回复——需逐对象回执可对账；**评价回复发布后不可撤回**，故 STG-06 对评价类动作实行发布前强制复核而非事后补救。
- 恢复：冻结解除后从断点继续；Service Evidence Pack 版本化保留；跨渠道口径冲突未决前不做合并统计。

## 验收与经济性

- **产物验收**：Service Evidence Pack 来源齐全率 100%；每条客户触达草稿通过话术规范与 PII 检查；每个退款/补偿建议带金额依据与权限级别；VOC 摘要每条结论带证据引用；跨渠道指标口径差异显式标注。
- **经营指标**：首响/解决时长、CSAT、退货率与退货原因结构、评价评分与响应率、VOC→产品反馈周期、服务动作回执完整率。
- **双层 KPI 关系**：FLOW-05 绑定时验收看问题解决率与复购代理指标；「体验」对品牌资产的影响（L2 满意度/口碑）经 `correlation_id` 移交 FLOW-09 Case 核算，不在本 Case 归因。服务指标改善但品牌指标恶化的冲突信号触发 AGT-005 复核。
- **经济性门槛**：首个周期以「PII 范围经 AGT-044/050 确认 + 平台规则校验通过 + 所有客户触达动作可对账 + VOC 回流被下游 Case 实际引用」为验收前提。
- **必须回放**：Amazon 买家站外联系请求（应被红线拦截）；评价激励话术（应被平台规则拦截）；超权限退款（应被 Policy Gate 拦截）；VOC 少量负面被写成「产品普遍缺陷」结论（应被证据引用检查拦截）；跨渠道退货率被直接平均（应被口径规则拦截）。
