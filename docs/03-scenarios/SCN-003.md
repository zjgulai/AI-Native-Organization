# SCN-003：产品机会评估与立项

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-02（新品：需求证据到商业验证）绑定时为 AGT-008 拓新；FLOW-08（经营复盘与资源更新）绑定时为 AGT-001。依据：D-025、D-078、PB-002、[品牌增长方法论](../06-playbooks/BRAND-GROWTH-METHODOLOGY.md) 第 4 节「消费者洞察」「出海」。

适用说明：本场景回答「这个产品机会值不值得投」——是品牌组合决策的上游闸门。FLOW-02 绑定时 AGT-008 拓新对「需求证据→商业验证结论」负责；涉及资源/能力版本变更的复盘维度经 `correlation_id` 关联 FLOW-08 Case。品牌视角内建：机会评估不只看市场规模，更看**与品牌定位的契合度**（品类延伸是否稀释核心心智）与**证据链完整度**（书2「敢为人先」须以消费者洞察为前提而非赌性）。

## 经营目的与范围

把产品机会转化为**有证据分级、有停止条件、有投入上限的立项决策包**，让新品投入建立在可验证假设而非直觉上。

- 业务对象：产品机会线索（市场信号/VOC 聚类/竞品动态/供应链能力）、商业假设包（人群×场景×价值主张×经济模型）、立项评审、停止/转向/继续三态结论；不含产品功能定义细节（SCN-004/FLOW-02 下游）、市场进入执行（SCN-005/FLOW-04）、投放与定价（SCN-011/010）。
- 范围内：机会信号聚合 → 假设结构化 → 证据分级收集 → 商业模型测算 → 立项建议（继续/转向/停止）→ Action Intent（立项申请/验证实验预算）→ 结果回流。
- 范围外：不替商业决策拍板（AI 给证据与建议，立项权属经营层）；不做产品设计与开发（SCN-004）；不做渠道准入判断（SCN-005）；不做品牌定位重定义（AGT-029/SCN-002 上游）。
- 不适用：无市场信号支撑的「我觉得好」型机会（先回 SCN-002 补洞察）；已立项产品的阶段性评审（归 FLOW-02 在制 Case 而非新建 SCN-003）。

## 触发与输入

### 触发

- 经营节奏：季度产品组合评审、年度新品规划、在制项目阶段门（继续/停止）。
- 信号触发：SCN-002 洞察产出可立项机会、VOC 聚类出现未满足需求、竞品新品验证市场、供应链成本窗口开启、品牌定位更新要求品类补强。
- 结构触发：在制项目连续两轮未达验证标准、机会池积压超容量、同一赛道多个机会需排序。

## 业务闭环

1. **STG-01 信号接收**：机会线索按「来源×品类×证据等级」聚合；在制项目阶段门信号与新机会信号分流建档。
2. **STG-02 建单**：Case Charter 固定主价值流（FLOW-02 为主，FLOW-08 关联不兼）、主场景 SCN-003、范围（机会集合/品类边界/评审周期）、投入上限声明。
3. **STG-03 上下文装配**：固定对应岗位 Release Bundle；装载机会评估与商业建模 Skills；只读市场/VOC/竞品/财务/供应链工具；品牌定位与品类边界版本。
4. **STG-04 证据与诊断**：业务贡献方产出 Opportunity Evidence Pack（市场信号、VOC 主题、竞品对标、经济模型初算、供应链可行性、品牌契合度评估）；诊断将每个机会标注证据等级（measured/proxy/book_reported/hypothesis）并识别关键假设——「最大的假设错了整个机会就不成立」的假设优先列出。
5. **STG-05 方案产物**：「立项建议包」——每机会一页：假设陈述、证据清单与等级、关键风险、验证路径（最小实验设计）、经济模型区间、品牌契合度、三态建议（继续/转向/停止）与所需投入；机会间排序建议（若为组合评审）。
6. **STG-06 Assurance 门禁**：确定性校验（schema、证据引用完整、假设显式标注、投入上限未超）+ AGT-005 语义复核（证据等级是否虚高、经济模型是否隐藏乐观假设、品牌契合度是否真引用定位版本而非印象）。
7. **STG-07 受控动作**：获批建议拆为 Action Intent——立项申请（内部审批流）、验证实验预算申请、机会池状态更新；当前阶段全部 `NoActionRecord` 或内部审批 Intent。
8. **STG-08 核验与关闭**：立项决策回执与后续跟踪挂钩；验证结果回流修正假设；机会池状态更新；关闭后学习提取回流（哪些证据等级预测准确、哪些假设常被证伪）。

## 授权与例外

- **允许**：只读市场/VOC/竞品/财务/供应链数据；产出评估、建模、建议与内部 Action Intent；跨 Case 引用已验收 Artifact。
- **冻结条件**：关键假设无任何证据支撑且无法设计验证实验；品牌定位版本缺失导致契合度无法判断；经济模型所需成本/价格数据缺失；机会池容量已满且无优先级规则。
- **高风险动作分级**：超预算验证实验、进入新品类（超出现有品类边界）、涉及新供应商开发——逐对象单独审批。
- **歧义处理**：机会证据不足时默认结论为「需补证」而非「可立项」；证据冲突时并列呈现不取平均。
- **重复与部分失败**：同一机会跨周期重复评估时关联既有 Case 更新而非新建；部分数据源缺失时对应维度标 `unknown` 降低置信度；Worker 产物不合格退回 STG-04。

## 接管与恢复

- 停止条件**：连续两轮补证不满足最小输入；发现证据等级被系统性高估；立项预算被批但验证路径不可行；品牌定位更新导致既有评估全部失效。
- 冻结范围**：仅冻结受影响机会/品类；已批准的立项不受本 Case 冻结影响（归在制 FLOW-02 Case 管理）。
- 已产生外部效果**：立项申请、预算申请——需回执可对账；验证实验已启动的由实验 Case 管理，本 Case 只引用其产物。
- 恢复**：冻结解除后从断点继续；Opportunity Evidence Pack 版本化保留；品牌定位版本更新后既有评估标记 `needs_revalidation`。

## 验收与经济性

- **产物验收**：每个机会假设显式列出且证据等级标注 100%；关键假设与验证路径一一对应；经济模型给区间不给点估计；三态建议均有可执行下一步；品牌契合度引用定位版本号。
- **经营指标**：立项决策周期、机会池转化率（机会→立项→上市→达标）、假设证伪率、验证实验成本与产出比、停止决策的及时性（坏机会早停率）。
- **双层 KPI 关系**：本场景产出的是**未来的**品牌资产——新品成功沉淀品类认知，失败消耗品牌信用（尤其母婴品类信任敏感）；立项对 GMV 的预期影响是假设不是结果，实际核算在 FLOW-02 在制 Case 与 SCN-016 结算 Case。
- **经济性门槛**：首个周期以「至少三次机会评审完成且每次有明确三态结论 + 一次验证实验设计被采纳」为验收前提。
- **必须回放**：hypothesis 证据被写成 measured（应被证据分级检查拦截）；经济模型只给乐观点估计（应被区间要求拦截）；品牌契合度凭印象未引定位版本（应被引用检查拦截）；坏消息证据被选择性忽略（应被 AGT-005 复核拦截）；机会重复建 Case 导致评审碎片化（应被 dedupe 规则拦截）。
