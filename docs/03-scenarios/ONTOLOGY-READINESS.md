# 场景本体就绪度矩阵

状态：v1 评估基线。依据：[SEMANTIC-LAYER-STRATEGY](../08-data/SEMANTIC-LAYER-STRATEGY.md) §5、《本体驱动的AI数据管理》§8.1.3 优选/排除标准。用途：决定 20 个场景中哪些优先建语义契约，避免「逢场景必建本体」的过度工程。

## 1. 评估维度

| 维度 | 含义 | 优选信号 | 排除信号 |
| --- | --- | --- | --- |
| 语义复杂度 | 场景涉及的业务对象/术语/跨域关系多少 | 跨域协同、术语歧义多 | 单一对象、语义简单 |
| 规则明确度 | 事理规则能否显性化为「如果…那么…」 | 规则体系明确、阈值/口径可定义 | 规则模糊、依赖主观判断 |
| 合规要求 | 对可追溯/可审计/权限边界的要求 | 高合规（资金/账号/隐私/对外承诺） | 低风险内部分析 |
| 外部动作风险 | 是否产生 Action Intent/外部执行 | 诊断型（零动作）最优先 | 受控动作型最后验证 |

**分级**：优先建模（语义价值高+风险低）→ 可选建模（按需）→ 暂不建模（收益低或条件不成熟）。

## 3. 分级逻辑

**优先建模（4 个）**：SCN-002/016/013/009——共同特征：诊断或对账型为主、语义对象跨域且术语歧义真实存在（Amazon vs DTC 口径、结算口径、品牌资产指标口径）、合规要求中高、外部动作风险低或为零。语义层在这里能立即减少「口径解释成本」。

**可选建模（10 个）**：语义复杂度或规则明确度满足一项但不全部，或动作风险中等——待优先组验证模板后按波次跟进。

**暂不建模（5 个，含 1 个可选边界）**：SCN-001/017/019 语义对象少（管理层场景）且动作风险高；SCN-006 采购动作风险高；SCN-020 属底座自身监控，语义需求随底座建设自然产生，不单独立项。

## 4. 与波次规划的关系

| 波次 | 场景 | 语义底座动作 |
| --- | --- | --- |
| 第一波·诊断型 | SCN-002/013/016/015 | 建 v0 语义契约（术语+对象+事理规则） |
| 第二波·建议型 | SCN-009/011/012/010/003/005 | 复用 v0 + 扩展域对象 |
| 第三波·受控动作型 | SCN-014/018/007/008/004/006 | 补权限语义声明后接入 |
| 支撑层 | SCN-001/017/019/020 | 暂不单独建模，随底座演进自然覆盖 |

## 5. 维护规则

- 场景规格升级（v1→v2）或新场景进入目录时，同步复评就绪度；
- 「暂不建模」不是永久排除——当场景转为诊断型或语义歧义暴露为实际问题时可重评；
- 本矩阵为评估基线，不替代场景规格中的业务判断。
