# SCN-006：供应商、采购与生产协作

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-03（供需：补货、采购与交付）绑定时为 AGT-016 知量；FLOW-02（新品）绑定时为 AGT-008 拓新；FLOW-07（重大事件）绑定时为 AGT-018 质守。依据：D-025、D-026、D-078、PB-003、PB-007。

适用说明：本场景覆盖供应商全生命周期——寻源、评估、合同、下单、生产跟踪、质量协同、交付验收。FLOW-03 绑定时 AGT-016 知量对「采购承诺与质量/成本/交期结果闭环」负责；供应商质量事故升级为重大事件时拆 `correlation_id` 关联的 FLOW-07 Case。Momcozy 适用性高：ODM/OEM 模式下供应商质量直接决定产品质量，单一来源依赖是供应链风险核心。

## 经营目的与范围

把供应商协作转化为**有评估、有承诺、有跟踪、有验收的采购闭环**，让「货能不能按时按质按量到」有据可查。

- 业务对象：供应商寻源与评估（资质/产能/质量/价格）、采购合同与 MOQ、采购订单与交期跟踪、来料检验与质量协同、供应商绩效评估、供应商风险（单一来源/地缘/财务）；不含需求预测（SCN-007）、产品定义（SCN-004）、运输执行（SCN-008）、结算对账（SCN-016）。
- 范围内：供应商信号监测 → 评估与选择建议 → 采购建议 → Action Intent（下单/验收/索赔/切换）→ 到货回执核验 → 绩效与风险复盘。
- 范围外：不直接签合同/下订单/验收（当前无授权，全部 `NoActionRecord` 或 Action Intent）；不做需求预测（SCN-007）；不做产品设计（SCN-004）；不做运输安排（SCN-008）；不做结算对账（SCN-016）。
- 不适用：无供应商基线数据（先建档案再谈评估）；供应商关系独家且无替代方案（风险标注 `sole_source` 但不擅自切换）。

## 触发与输入

### 触发

- 经营节奏：月度供应商绩效评审、季度寻源评估、新品开发供应商匹配、合同到期续签、质量问题升级。
- 信号触发：交期延误、来料不良率超标、价格上涨、产能不足、供应商资质变化、地缘/政策风险、竞品供应商动态。
- 结构触发：单一来源依赖集中、同一供应商多产品线质量问题、采购量与产能不匹配、合同条款缺失或过期。

## 业务闭环

1. **STG-01 信号接收**：供应商绩效、采购订单、质量数据、市场情报、合同到期分别建档；风险信号与机会信号分流。
2. **STG-02 建单**：Case Charter 固定主价值流（FLOW-03 为主，FLOW-02/07 关联不兼）、主场景 SCN-006、范围（供应商/SKU/品类/采购周期）、采购与质量约束声明。
3. **STG-03 上下文装配**：固定对应岗位 Release Bundle；装载供应商评估与采购优化 Skills；只读供应商档案/采购/质量/库存工具；市场情报与法规版本库。
4. **STG-04 证据与诊断**：AGT-014 组织 Supplier Evidence Pack（供应商档案、采购历史、质量记录、市场情报、合同条款、库存需求）；诊断输出供应商分级（战略/优选/备选/观察/退出）、风险清单（单一来源/质量/交期/价格/合规）、采购优化空间（量价/交期/品类分配）。
5. **STG-05 方案产物**：「供应商行动包」——逐供应商建议（续约/切换/分级调整/改进要求/退出）、采购计划建议（量/价/时点/渠道分配）、合同修订建议、风险缓释措施（备选供应商开发/安全库存调整）；每条标注证据引用与可证伪条件。
6. **STG-06 Assurance 门禁**：确定性校验（资质有效期、MOQ/产能约束、合同覆盖、schema、成本测算完整）+ AGT-005 语义复核（评估是否有数据支撑、切换是否考虑过渡成本、风险是否遗漏、合同建议是否有法律依据）。
7. **STG-07 受控动作**：获批方案拆为 Action Intent——采购订单建议、验收指令、索赔、供应商切换、合同修订；当前阶段全部 `NoActionRecord` 或内部审批 Intent。
8. **STG-08 核验与关闭**：到货/验收/付款回执核验；供应商绩效更新；采购成本与质量复盘；关闭后学习提取回流（哪些供应商稳定、哪些风险高频、哪些评估维度有效）。

## 授权与例外

- **允许**：只读供应商/采购/质量/库存/市场数据；产出评估、建议、Action Intent 与风险分析；跨 Case 引用已验收 Artifact。
- **冻结条件**：供应商档案缺失或过期；资质证书无效；合同条款不明；质量数据口径不一致；市场情报来源单一；库存需求未对齐。
- **高风险动作分级**：供应商切换（影响在产产品）、合同重大修订、批量索赔、退出供应商——逐对象单独审批；AI 不得出具「供应商合格」结论只出具证据与建议。
- **歧义处理**：供应商评估数据不足时标 `insufficient_data` 并降低置信度；质量问题归因不清时标 `unattributed` 并扩大证据范围。
- **重复与部分失败**：同一供应商跨周期重复评估时关联既有 Case 更新；部分数据源缺失时只冻结受影响维度；Worker 产物不合格退回 STG-04。

## 接管与恢复

- 停止条件：连续两轮补证不满足最小输入；发现供应商资质造假或重大违规；质量问题升级为重大安全事件；合同纠纷进入法律程序。
- 冻结范围：仅冻结受影响供应商/SKU/采购批次；已执行的采购/验收由执行 Case 管理，本 Case 只引用回执。
- 已产生外部效果：采购订单、验收、索赔、切换——需回执可对账；切换后新供应商质量问题的标 `transition_risk` 进入 SCN-004 跟踪。
- 恢复：冻结解除后从断点继续；Supplier Evidence Pack 版本化保留；资质/合同/法规版本更新后既有评估标记 `needs_revalidation`。

## 验收与经济性

- **产物验收**：Evidence Pack 五源齐全率 100%；每个供应商分级有评估依据；每个采购建议有约束校验；每个风险有缓释措施；合同建议有法律审查标记。
- **经营指标**：供应商交期达成率、来料合格率、采购成本偏差、单一来源占比、供应商切换周期、索赔成功率、评估覆盖率。
- **双层 KPI 关系**：本场景是**产品质量与成本的上游**——供应商质量影响产品质量（SCN-004 关联）与品牌信任（FLOW-09 关联）；采购成本影响毛利（FLOW-01 关联）；供应商风险影响交付稳定性（FLOW-03 关联）。
- **经济性门槛**：首个周期以「供应商分级评估完成 + 至少一次采购建议被采纳 + 质量/交期指标可测」为验收前提。
- **必须回放**：档案缺失供应商被推荐（应被 `unverified` 规则拦截）；资质过期仍作为合格依据（应被有效期校验拦截）；切换建议未考虑过渡成本（应被成本完整性检查拦截）；单一来源风险被忽略（应被风险清单规则拦截）；合同建议无法律审查标记（应被 AGT-043 边界拦截）。
