# SCN-011：广告投放与预算调整

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-09 绑定时为 AGT-029 立言（品牌资产与投放联合经营口径）；FLOW-01（GMV）绑定时以该流结果负责人为准（BVS-01 现为 AGT-023）。依据：D-078、PB-009、[品牌增长方法论](../06-playbooks/BRAND-GROWTH-METHODOLOGY.md) 第 7 节「品效合一」、书2 第 19/20/21/25 章框架。

适用说明：投放是全场景中外部动作密度最高者，也是「品效张力」最集中的场景——同一投放 Case 在 FLOW-09 下要回答「这笔钱沉淀了多少品牌资产」，在 FLOW-01 下要回答「这笔钱带来多少当期 GMV」。D-025 要求二者拆为两个 Case 用 `correlation_id` 关联，不允许一个 Case 同时背两层结果责任。

## 经营目的与范围

把广告预算转化为**可解释、可归因、可回滚的投放决策**，并显式管理「品牌资产（品）」与「当期效果（效）」两个结果层。

- 业务对象：广告账户（Amazon Ads、Google/Meta 等独立站投放）、SKU 集合、预算包、人群与素材；不含自然流量运营与内容生产（属 SCN-012/009）。
- 范围内：投放诊断 → 预算/出价/素材假设 → 实验或受控调整方案 → 逐对象 Action Intent → 回执核验 → 品效双层归因。
- 范围外：不直接在广告后台操作（当前无授权，全部 `NoActionRecord` 或 Action Intent）；不做品牌策略定义（属 SCN-002/AGT-029 上游）；不替代定价决策（SCN-010）。
- 不适用：无投放历史基线的新账户（先建基线再谈优化）；品牌广告与效果广告未分层的混合账户（先拆分口径，属 AGT-045/SCN-020 数据治理）。

## 触发与输入

### 触发

- 经营节奏：月度投放复盘、季度预算分配、大促前计划与大促后归因。
- 信号触发：ACOS/ROAS 趋势拐点、预算消耗异常、素材疲劳信号、竞品广告位变化、品牌词搜索量与广告流量背离。
- 结构触发：品效结构偏差（品牌指标升而效指标降或反之）、归因窗口争议、增量评估需求。

### 输入

| 输入类 | 来源（候选，待确认接入） | 质量要求 |
| --- | --- | --- |
| 投放数据 | Amazon Ads 报表、Google/Meta Ads API、第三方归因工具 | 口径与 AGT-045 契约一致；区分平台归因与自有归因 |
| 交易数据 | 广告引流订单、自然订单、品牌词订单 | 可归因/不可归因分列；原始订单不出 Connector（D-047/048） |
| 品牌资产数据 | 品牌词搜索指数、直接访问、认知/声量指标 | 长周期口径，标注归因局限；书中品效倍数不作实测 |

## 责任与参与者

- **AI 结果负责人**：FLOW-09 绑定时 AGT-029（对「投放是否沉淀品牌资产」负责）；FLOW-01 绑定时以 BVS-01 结果负责人为准。两层结果不得由同一 Case 兼负。
- **业务贡献**：AGT-032 效果广告投放（账户事实与优化假设）、AGT-035 增长实验与增量评估（实验设计与因果判断）、AGT-041 经营财务（预算约束与毛利底线）、AGT-045 业务口径（指标口径与归因窗口）。
- **编排**：AGT-002 / 模型外 Case Control。
- **独立复核**：AGT-005——检查归因是否误用平台自归因、实验是否可识别、预算动作是否超 Charter。
- **外部执行主体**：广告平台 API/后台——当前未授权连接；执行动作只以 Action Intent 存在。

## 业务闭环

1. **STG-01 信号接收**：投放数据按日/周聚合；品效结构偏差、预算消耗异常与节奏复盘分别建档。
2. **STG-02 建单**：Case Charter 固定主价值流（FLOW-09 或 FLOW-01，不可兼）、主场景 SCN-011、范围（账户/SKU/预算包/时间窗）、完成条件与预算上限声明。
3. **STG-03 上下文装配**：固定对应岗位 Release Bundle；装载 SKL-BRAND-02（品效归因实验设计）与投放诊断 Skills；只读数据工具；品牌定义与投放策略版本。
4. **STG-04 证据与诊断**：AGT-032/035 产出 Spend Evidence Pack（消耗、转化、归因分层、素材表现、竞品位）；结果负责人形成 Diagnosis Record——区分「平台归因的相关性」与「可干预的因果」；品效结构按书2「冰山模型」分层表述（品牌广告长期复利 vs 效果广告短期衰减）。
5. **STG-05 方案产物**：「投放调整与实验包」——候选动作（出价/预算/素材/人群）、双层预期（品牌资产指标 + 当期 GMV/订单）、实验或灰度设计、停止条件、所需预算与依赖；每条标注可证伪条件。
6. **STG-06 Assurance 门禁**：确定性校验（预算不超 Charter、schema、口径一致）+ AGT-005 语义复核（归因声明是否越界、品效是否被错误合并为单一 ROI、停止条件是否可执行）。
7. **STG-07 受控动作**：获批方案拆为逐对象 Action Intent → Policy Gate 判定 → Execution Broker 执行 → 逐对象回执；拒绝/异常记入 Case Ledger。当前阶段无授权连接时全部 `NoActionRecord`。
8. **STG-08 核验与关闭**：回执与结果核验；双层归因报告（FLOW-09 看品牌资产长周期，FLOW-01 看当期 GMV）；冲突信号触发复核；关闭后学习提取回流。

## 授权与例外

- **允许**：只读投放/交易/品牌数据；产出诊断、实验设计与 Action Intent；跨 Case 引用已验收 Artifact。
- **冻结条件**：广告平台凭据/权限缺失；预算上限未在 Charter 声明；归因口径冲突未决；品效层未分离导致无法双层表述；输入超出范围。
- **歧义处理**：建单前歧义记 Pre-Case Exception；范围内歧义在 STG-04 标注并缩小结论。
- **重复与部分失败**：同 `case_dedupe_key` 关联既有 Case；部分平台数据缺失时只冻结受影响平台分支；Worker 产物不合格退回 STG-04。

## 接管与恢复

- 停止条件：连续两轮补证不满足最小输入；发现投放数据系统性口径错误；预算动作被判定超 Charter 且无降级方案。
- 冻结范围：仅冻结受影响账户/平台/结论分支；已执行的 Action Intent 由执行 Case 的 Recovery Contract 负责回滚，本 Case 只引用回执。
- 已产生外部效果：投放消耗、预算调整——需逐对象回执可对账；无法对账的动作视为未闭环，不得计入结果。
- 恢复：冻结解除后从断点继续；Spend Evidence Pack 版本化保留。

## 验收与经济性

- **产物验收**：Spend Evidence Pack 来源齐全率 100%；每个调整假设带双层预期、可证伪条件、停止条件与预算上限；归因结论标注方法（AB/MTA/MMM/平台自归因）与局限声明；量化表述三级来源标注。
- **经营指标**：投放→可解释增量的转化率；归因置信度分布；预算动作回执完整率；品效双层指标的口径一致性。
- **双层 KPI 关系**：FLOW-09 绑定时验收看品牌资产指标长周期变化（认知/声量/直接访问）是否被投放沉淀，GMV 只作护栏；FLOW-01 绑定时看当期增量 GMV，但必须同时核对品牌资产护栏。GMV 升而品牌指标降（或反之）的冲突信号触发 AGT-005 复核，不得取平均。
- **经济性门槛**：首个周期以「归因方法合规 + 实验设计通过复核 + 所有预算动作可对账」为验收前提。
- **必须回放**：平台自归因被当作因果增量（应被 SKL-BRAND-02 局限声明拦截）；品牌广告与效果广告混算为单一 ROI；预算动作超 Charter 被执行（应被 Policy Gate 拦截）；书中品效倍数被当作 Momcozy 实测。
