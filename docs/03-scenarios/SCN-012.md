# SCN-012：品牌内容、站外营销与活动

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-09 绑定时为 AGT-029 立言；FLOW-05（客户旅程）绑定时以该流结果负责人为准。依据：D-078、PB-009、[品牌增长方法论](../06-playbooks/BRAND-GROWTH-METHODOLOGY.md) 第 3 节「传播与内容」与第 5 节「品牌定义」、书2 第 14/15/16/17/22 章框架。

适用说明：本场景是品牌资产经营的「对外表达层」——内容、活动与站外营销既是触达手段也是品牌资产本身的载体。与 SCN-009（商品 Listing/上架执行）的边界：本场景管「为什么说、对谁说、说得好不好」，SCN-009 管「商品信息是否正确上架」。与 SCN-011（投放）的边界：本场景管内容与活动策略，投放管预算与出价执行。

## 经营目的与范围

把品牌传播、内容生产与站外活动转化为**与品牌定义一致、可衡量反馈、可沉淀为资产的对外表达**。

- 业务对象：品牌内容矩阵（Listing/A+、独立站内容、社媒素材、邮件/私域内容）、站外活动（达人合作、联盟、PR、线下/线上 campaign）、内容与活动的人群与渠道；不含商品信息正确性（SCN-009）与广告出价预算（SCN-011）。
- 范围内：内容需求与策略 → 内容生产/策划 → 合规与品牌一致性审核 → 发布执行（Action Intent）→ 反馈采集 → 资产归因。
- 范围外：不直接发布内容到任何平台（当前无授权）；不做达人合同签署与付款（商务动作另行授权）；不做商品 Listing 修改（SCN-009）。
- 不适用：纯商品信息纠错（SCN-009）；纯投放优化（SCN-011）；无品牌定义版本的内容生产（先回 SCN-002/品牌定义共创）。

## 触发与输入

### 触发

- 经营节奏：内容日历周期、季度品牌 campaign、大促主题活动、新品上市配套内容。
- 信号触发：内容表现拐点（互动/转化/声量）、品牌词搜索异动、竞品内容策略变化、VOC 中内容相关诉求聚类、平台规则/合规政策变化。
- 资产触发：品牌定义/品牌理想版本更新、内容资产库缺口盘点、达人合作机会信号。

## 业务闭环

1. **STG-01 信号接收**：内容日历节奏、表现拐点、品牌定义更新与合规变化分别建档。
2. **STG-02 建单**：Case Charter 固定主价值流、主场景 SCN-012、范围（渠道/人群/内容类型/时间窗）、完成条件；声明品牌资产与经营双层预期。
3. **STG-03 上下文装配**：固定 AGT-029 Release Bundle；装载内容策略与合规 Skills、品牌定义版本、只读数据工具。
4. **STG-04 证据与诊断**：AGT-030/031/033 产出 Content Evidence Pack（需求依据、历史表现、合规约束、素材可用性）；结果负责人形成 Diagnosis Record——内容机会按书2「五标准」（准确信息/吸睛/场景/易传播/调性一致）与「传播三位一体」（场景+媒体+渠道）诊断覆盖缺口。
5. **STG-05 方案产物**：「内容与活动包」——内容清单（每条含目标人群/渠道/品牌定义锚点/预期双层指标）、活动方案（达人/联盟/PR/线下）、合规自查清单、发布顺序与依赖、停止条件。
6. **STG-06 Assurance 门禁**：确定性校验（合规规则匹配、品牌定义一致性 schema、素材版权标注）+ AGT-005 语义复核（内容主张是否有证据支撑、效果预期是否合理、是否越界承诺）。
7. **STG-07 受控动作**：获批内容包拆为逐对象 Action Intent（每条内容/每个活动一个意图）→ Policy Gate 判定 → Execution Broker 执行 → 回执；当前阶段全部 `NoActionRecord`。
8. **STG-08 核验与关闭**：发布回执与表现数据核验；品牌资产与经营双层归因；关闭后内容表现与假设验证结果回流为内容知识资产。

## 授权与例外

- **允许**：只读内容/表现/合规数据；产出内容策略、创意脚本、合规自查与 Action Intent；跨 Case 引用已验收 Artifact。
- **冻结条件**：品牌定义版本缺失或过期；合规规则库未覆盖目标市场；素材版权/授权状态不明；内容主张缺乏证据支撑；输入超出 Charter 范围。
- **歧义处理**：建单前歧义记 Pre-Case Exception；范围内歧义在 STG-04 标注并缩小结论（如不确定的功效宣称必须删除而非弱化）。
- **重复与部分失败**：同 `case_dedupe_key` 关联既有 Case；部分渠道权限缺失时只冻结该渠道分支；内容被平台拒审时记入 Case Ledger 并触发合规复审。

## 接管与恢复

- 停止条件：连续两轮补证不满足最小输入；品牌定义版本无法确定；合规规则缺失且无法人工确认；内容包被 AGT-005 判定系统性越界。
- 冻结范围：仅冻结受影响渠道/内容类型/活动分支。
- 已产生外部效果：已发布内容可下架/撤回——由执行 Case 的 Recovery Contract 负责，本 Case 只引用回执与下架结果。
- 恢复：冻结解除后从断点继续；Content Evidence Pack 与内容包版本化保留。

## 验收与经济性

- **产物验收**：内容包中每条内容有品牌定义锚点、目标人群、渠道、预期双层指标与合规自查结果；合规自查覆盖率 100%；量化效果预期标注「假设/历史参照/书中报告」来源。
- **经营指标**：内容→反馈的转化率；品牌一致性合规通过率；内容资产复用率；达人/活动合作的可归因结果占比。
- **双层 KPI 关系**：FLOW-09 绑定时验收看品牌资产指标（声量/认知/品牌词搜索）与内容资产沉淀；FLOW-05 绑定时看客户旅程触点效果。内容带来的短期转化与长期品牌资产分别核算，不以单次活动 GMV 替代品牌结论。
- **经济性门槛**：首个周期以「内容包合规通过率 100% + 品牌定义一致性经复核 + 每条内容可追溯」为验收前提。
- **必须回放**：内容主张无证据支撑被发布（应被 Assurance 拦截）；品牌定义版本过期后仍生产内容（应冻结）；达人合作效果被当作自然流量归因（口径违规）；书中传播效果倍数被当作 Momcozy 实测。
