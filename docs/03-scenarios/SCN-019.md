# SCN-019：组织、人员与绩效改进

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-08（经营复盘、资源和组织能力更新）绑定时为 AGT-001 衡远。依据：D-025、D-053、D-078、PB-008。

适用说明：本场景是唯一**单流绑定**场景——组织、人员与绩效改进纯属 FLOW-08/AGT-001 的职权范围。本场景对 AI 组织自身有双重意义：(1) 管理未来真人团队与 HITL 的职责/能力/负荷设计（后置设计，D-053 保留方向）；(2) 管理 50 个 AI 岗位分身的**能力版本与绩效演进**——岗位不是静态配置而是有生命周期、有效期与回退机制的版本化资产。AGT-004 知人是组织能力与人事行政的第一贡献者。

## 经营目的与范围

把组织与人员管理转化为**有职责边界、有能力评估、有绩效回路的组织闭环**，让「谁负责什么、能力够不够、表现如何改进」有据可查。

- 业务对象：组织架构与职责分工（真人团队+AI 岗位+外包/供应商）、人员能力评估与发展、绩效指标与考核、编制与负荷管理、组织变革（岗位增删/合并/升级）；不含具体业务执行（各 SCN Case）、预算分配（SCN-001）、数据平台建设（SCN-020）。
- 范围内：组织信号监测 → 职责/能力/负荷诊断 → 改进建议（岗位调整/培训/编制/流程）→ Action Intent（人事变动/岗位配置/绩效面谈）→ 执行回执核验 → 绩效复盘。
- 范围外：不直接执行人事变动/岗位配置/绩效考核（当前无授权，全部 `NoActionRecord` 或内部审批 Intent）；不做业务决策（各 FLOW Case）；不做预算分配（SCN-001）；不做 AI 岗位技术实现（DSH Preset 归 ROLE-PRESET-IMPLEMENTATION-TODO）。
- 不适用：无组织架构版本或职责矩阵（先建框架再谈诊断）；纯 AI 岗位无真人对应（能力评估标准需另行定义）。

## 触发与输入

### 触发

- 经营节奏：年度组织评审、季度绩效周期、月度负荷检查、重大业务变化后组织调整。
- 信号触发：职责冲突/空白、能力缺口、负荷不均、绩效异常、人员流失风险、组织变革需求（扩张/收缩/转型）、AI 岗位能力版本过期。
- 结构触发：部门墙阻碍协作、关键岗位单点依赖、绩效指标与经营目标脱节、AI 与真人职责边界模糊。

- **外部执行主体**：HR 系统/绩效系统/招聘平台——当前未授权连接；人事变动/岗位配置/绩效面谈只以 Action Intent 存在。

## 业务闭环

1. **STG-01 信号接收**：组织架构版本、人员变动、负荷数据、绩效结果、AI 岗位状态分别建档。
2. **STG-02 建单**：Case Charter 固定主价值流 FLOW-08、主场景 SCN-019、范围（部门/岗位/人员群/周期）、人事权限上限声明。
3. **STG-03 上下文装配**：固定对应岗位 Release Bundle；装载组织诊断与绩效分析 Skills；只读组织/人员/业务/AI 岗位工具；法规与合规版本库。
4. **STG-04 证据与诊断**：AGT-004 组织 Org Evidence Pack（架构版本、职责矩阵、负荷分布、绩效数据、能力评估、AI 岗位状态）；诊断识别职责冲突/空白、能力缺口、负荷不均、绩效脱节、AI-真人边界模糊；区分「结构问题」（架构缺陷）与「执行问题」（个人/团队表现）与「环境问题」（业务变化）。
5. **STG-05 方案产物**：「组织行动包」——岗位调整建议（增/删/合并/升级）、职责重新分配建议、能力发展计划（培训/轮岗/招聘）、绩效改进建议（指标调整/考核方式）、AI 岗位能力版本更新建议；每条标注证据引用与可证伪条件。
6. **STG-06 Assurance 门禁**：确定性校验（编制合规、职责不冲突、绩效指标口径、schema、法规要求）+ AGT-005 语义复核（诊断是否有证据、建议是否考虑过渡成本、人事建议是否合规、AI-真人边界是否清晰）。
7. **STG-07 受控动作**：获批方案拆为 Action Intent——人事变动申请、岗位配置更新、绩效面谈安排、AI 岗位版本发布；当前阶段全部 `NoActionRecord` 或内部审批 Intent。
8. **STG-08 核验与关闭**：人事/配置执行回执与组织状态核验；绩效改进效果跟踪；组织健康复盘；关闭后学习提取回流（哪些诊断有效、哪些建议被采纳、哪些指标预测准确）。

## 授权与例外

- **允许**：只读组织/人员/业务/AI 岗位数据（脱敏）；产出诊断、建议、Action Intent 与合规校验；跨 Case 引用已验收 Artifact。
- **冻结条件**：组织架构版本缺失；职责矩阵不完整；人员数据权限不足；绩效指标口径不一致；AI 岗位状态不明；法规/合规要求未明确。
- **高风险动作分级**：人员裁员/重大岗位变动、薪酬调整、组织架构重组、AI 岗位权限变更——逐对象单独审批；AI 不得出具「解雇」或「录用」结论只出具证据与建议。
- **歧义处理**：职责边界不清时标注 `boundary_ambiguous` 并建议澄清而非强行分配；能力评估数据不足时标注 `assessment_insufficient` 并降低置信度。
- **重复与部分失败**：同一部门/岗位跨周期重复评估时关联既有 Case 更新；部分数据源缺失时只冻结受影响维度；Worker 产物不合格退回 STG-04。

## 接管与恢复

- 停止条件：连续两轮补证不满足最小输入；发现组织架构版本冲突；重大人事变动进行中；绩效指标体系变更；AI 岗位生命周期状态异常。
- 冻结范围：仅冻结受影响部门/岗位/人员群；已执行的人事/配置动作由执行 Case 管理，本 Case 只引用回执。
- 已产生外部效果：人事变动、岗位配置、绩效面谈、AI 岗位版本发布——需回执可对账；变动后组织冲突的标 `transition_conflict` 进入再诊断。
- 恢复：冻结解除后从断点继续；Org Evidence Pack 版本化保留；组织/法规/岗位版本更新后既有评估标记 `needs_revalidation`。

## 验收与经济性

- **产物验收**：Evidence Pack 四源齐全率 100%；职责诊断覆盖全部岗位；每个人事建议有合规校验；绩效指标与经营目标一致；AI-真人边界显式声明。
- **经营指标**：职责覆盖率、能力缺口数、负荷均衡度、绩效达成率、人效指标、AI 岗位产出质量、组织变革成功率。
- **双层 KPI 关系**：本场景是**组织能力的底座**——组织健康影响所有 FLOW 的执行效率；AI 岗位绩效直接影响 Case 产出质量（FLOW-06 关联）；人员成本影响预算（SCN-001 关联）；本 Case 不背业务结果只对组织事实与建议负责。
- **经济性门槛**：首个周期以「组织诊断报告完成 + 至少一个改进建议被采纳 + 绩效指标口径确认」为验收前提。
- **必须回放**：职责空白被忽略（应被覆盖率检查拦截）；绩效指标与经营目标脱节（应被一致性检查拦截）；人事建议无合规校验（应被法规检查拦截）；AI-真人职责边界模糊仍给出建议（应被边界声明规则拦截）；能力评估数据不足仍给出确定性结论（应被 `assessment_insufficient` 规则拦截）。
