# SCN-008：跨境运输与仓储履约

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-03（供需：补货、采购与交付）绑定时为 AGT-016 知量；FLOW-04（新市场、新渠道）绑定时为 AGT-024 拓域。依据：D-025、D-026、D-078、PB-003。

适用说明：本场景覆盖货物从工厂/供应商到客户手中的物理链路——跨境运输、清关、末端配送、仓储作业。FLOW-03 绑定时 AGT-016 知量对「供应计划与交付对齐」负责；新市场/新渠道的履约方案验证经 `correlation_id` 关联 FLOW-04 Case。异常升级为账号健康事件（时效恶化推高 ODR/LSR）时转 SCN-018。Momcozy 适用性极高：跨境电商履约是体验与成本的双重战场，清关延误与末端丢件是高频异常源。

## 经营目的与范围

把跨境运输与仓储履约转化为**可追踪、可预警、可优化的物流闭环**，让「货到不到、多久到、成本多少」都有据可查。

- 业务对象：头程运输（海运/空运/快递）、清关申报与查验、末端配送（FBA/FBM/3PL/邮政）、仓储作收发、逆向物流（退货入库/二次上架/销毁）；不含采购下单（SCN-006）、需求预测（SCN-007）、订单异常分诊（SCN-014——本场景提供物流事实，异常处置归 SCN-014）。
- 范围内：在途监控 → 预警与延误预判 → 物流方案评估（路径/成本/时效权衡）→ Action Intent（改派/改仓/加急/索赔）→ 到货回执核验 → 物流成本与时效复盘。
- 范围外：不直接操作承运商/3PL/仓库系统（当前无授权，全部 `NoActionRecord` 或 Action Intent）；不做采购决策（SCN-006）；不做需求预测（SCN-007）；不做订单级异常处置（SCN-014——本场景是其物流数据源）。
- 不适用：无在途/轨迹数据接入的物流商（先建数据接入再谈监控）；纯国内段无跨境环节（降级为常规仓储监控）。

## 触发与输入

### 触发

- 经营节奏：在途库存周会、月度物流成本复盘、季度路径优化评估、渠道入仓计划（FBA/Target/Walmart 截止日）。
- 信号触发：在途超时未到、清关查验/扣留、末端派送失败、运费异常上涨、渠道入仓截止风险、物流商 SLA 违约、目的国政策变更。
- 结构触发：同一路径批量延误（系统性问题）、多渠道入仓计划冲突、逆向物流积压、物流成本占比异常上升。

## 业务闭环

1. **STG-01 信号接收**：在途/清关/末端/仓储/逆向五类物流信号分别建档；延误预警与成本异常分流。
2. **STG-02 建单**：Case Charter 固定主价值流（FLOW-03 为主，FLOW-04 关联不兼）、主场景 SCN-008、范围（路径/渠道/仓/货类/周期）、时效与成本约束声明。
3. **STG-03 上下文装配**：固定对应岗位 Release Bundle；装载物流诊断与路径评估 Skills；只读在途/清关/仓储/成本工具；渠道入仓规范与目的国法规版本。
4. **STG-04 证据与诊断**：AGT-019 组织 Logistics Evidence Pack（在途轨迹、清关状态、仓储作业、成本明细、渠道要求）；诊断定位异常环节（揽收延误/干线延误/清关扣留/末端派送失败/仓内积压/逆向堵塞）并评估路径优化空间（时效 vs 成本 vs 风险三角）。
5. **STG-05 方案产物**：「物流行动包」——逐异常处置建议（改派/加急/清关协助/索赔/入仓调整）、路径优化建议（含成本-时效-风险测算）、渠道履约改进建议（移交 FLOW-04）、逆向处置建议；每条标注约束校验与可证伪条件。
6. **STG-06 Assurance 门禁**：确定性校验（禁运品合规、HS 编码、渠道入仓截止、成本上限、schema、口径一致）+ AGT-005 语义复核（路径评估是否遗漏清关风险、成本是否含关税/保险/仓租、时效承诺是否可兑现）。
7. **STG-07 受控动作**：获批方案拆为 Action Intent——承运商改派/加急指令、清关资料补正、索赔提交、入仓预约调整；当前阶段全部 `NoActionRecord` 或内部审批 Intent。
8. **STG-08 核验与关闭**：到货/签收/入库回执核验；物流成本与时效复盘；路径优化效果跟踪；关闭后学习提取回流（哪些路径稳定、哪些环节高频异常、哪些承运商 SLA 不可靠）。

## 授权与例外

- **允许**：只读在途/清关/仓储/成本数据；产出诊断、路径评估、Action Intent 与成本分析；跨 Case 引用已验收 Artifact。
- **冻结条件**：在途轨迹数据不可用且无法交叉验证；清关状态不明；目的国法规版本过期；渠道入仓要求变更未同步；物流成本数据缺失导致无法评估。
- **高风险动作分级**：路径变更（影响在途货物）、加急费用超预算、清关申报变更、批量索赔——逐对象单独审批。
- **歧义处理**：轨迹停滞无法判断是承运商延误还是清关问题时标注 `stalled_unknown` 并扩大证据而非猜测归因；多路径并行时分别评估不合并。
- **重复与部分失败**：同一在途批次跨 Case 重复评估时关联既有 Case；部分物流商数据缺失时只冻结受影响路径分支；Worker 产物不合格退回 STG-04。

## 接管与恢复

- 停止条件：连续两轮补证不满足最小输入；发现清关申报错误需紧急修正；渠道入仓截止已过且无替代方案；物流商系统性故障。
- 冻结范围：仅冻结受影响路径/渠道/仓；已提交的改派/加急指令由执行 Case 管理，本 Case 只引用回执。
- 已产生外部效果：改派指令、加急费用、索赔、入仓变更——需回执可对账；加急费用产生但时效未改善的记 `expedite_ineffective` 进入承运商评估。
- 恢复：冻结解除后从断点继续；Logistics Evidence Pack 版本化保留；目的国法规/渠道规则更新后既有路径评估标记 `needs_revalidation`。

## 验收与经济性

- **产物验收**：Evidence Pack 五源齐全率 100%；每个异常定位有轨迹/清关/仓储证据；路径评估含成本-时效-风险三维测算；每个 Action Intent 有约束校验结果。
- **经营指标**：准时到货率、清关延误率、末端派送成功率、物流成本占比、在途库存天数、索赔率与追回率、逆向处理时长。
- **双层 KPI 关系**：本场景是**体验与成本的交汇点**——物流时效影响客户体验（FLOW-05 关联）与账号健康（SCN-018 关联）；物流成本影响毛利（FLOW-01 关联）；品牌资产影响（配送体验=品牌触点）经 `correlation_id` 移交 FLOW-09。
- **经济性门槛**：首个周期以「至少一个完整在途周期监控闭环 + 一次路径评估或异常处置完成 + 物流成本可归因到路径」为验收前提。
- **必须回放**：轨迹停滞被直接判定为承运商延误而未排查清关（应被 `stalled_unknown` 规则拦截）；路径评估遗漏目的国禁运品（应被合规校验拦截）；成本测算遗漏关税/保险（应被成本完整性检查拦截）；时效承诺无承运商 SLA 依据（应被证据检查拦截）；加急费用超预算未审批（应被 Policy Gate 拦截）。
