# SCN-010：定价、促销与利润管理

状态：v1 设计规格；场景候选映射待企业验证。AI结果负责人：FLOW-01（GMV）绑定时以该流结果负责人为准（BVS-01 现为 AGT-023；Amazon 侧渠道经营另计）；FLOW-03（供需）绑定时为 AGT-016 知量。依据：D-078、PB-009、[品牌增长方法论](../06-playbooks/BRAND-GROWTH-METHODOLOGY.md) 第 6 节「量化投资」、书2 第 19/20/21 章框架。

适用说明：定价是「品效张力」的第二集中场景（仅次于 SCN-011 投放）——同一促销既改变当期 GMV/毛利（L1），也沉淀或透支「价格感知」品牌资产（L2，见[双层 KPI 字典](../08-data/FLOW-09-DUAL-KPI-CATALOG.md)）。D-025 要求价格 Case 只背主结果流的闭环责任；品牌资产影响经 `correlation_id` 关联的 FLOW-09 Case 单独核算，不允许一个 Case 同时背两层结果。

## 经营目的与范围

把价格与促销决策转化为**可解释、可约束、可回滚的价格行动包**，同时守住毛利底线、渠道价格纪律与品牌价格感知三条边界。

- 业务对象：SKU/产品族价格点、促销日历（Prime Day/黑五/站点大促）、优惠券与叠加规则、渠道价格一致性（Amazon/DTC/Target/Walmart/DME）、MAP 与折扣深度策略；不含广告出价（SCN-011）、商品成本核算（AGT-040 财务域）。
- 范围内：价格信号诊断 → 价格/促销假设 → 利润与库存约束校验 → 逐对象 Action Intent（改价/促销/优惠券）→ 回执核验 → 当期结果复盘。
- 范围外：不直接在各平台后台改价（当前无授权，全部 `NoActionRecord` 或 Action Intent）；不做品牌定位与价值主张定义（AGT-029/SCN-002 上游）；不替代库存补货决策（SCN-007/FLOW-03）。
- 不适用：无成本与毛利数据的 SKU（先补财务口径，属 AGT-040/SCN-020）；渠道间价格政策未定义的市场（先定纪律再谈优化）。

## 触发与输入

### 触发

- 经营节奏：促销日历节点（大促前 4–6 周计划、大促后复盘）、月度价格健康检查、季度价格策略回顾。
- 信号触发：竞品价格变动、毛利率跌破阈值、库存周转恶化、渠道价格倒挂/违规警告、平台促销报名截止。
- 结构触发：价格感知指标与 GMV 背离（大促拉动 GMV 但伤价格认知）、渠道冲突（Amazon 与 DTC 价差投诉）、促销叠加错误。

- **业务贡献**：AGT-026 衡价（价格策略与假设主贡献）、AGT-016/017 知量/衡仓（库存约束与库龄）、AGT-040/041 清账/守金（成本、毛利底线与现金流窗口）、AGT-021/022/023/027 渠道侧（各平台价格事实与规则）、AGT-035 试真（价格弹性实验设计）。
- **编排**：AGT-002 / 模型外 Case Control。
- **独立复核**：AGT-005——检查毛利计算是否遗漏费用项、价格假设是否有弹性证据、渠道纪律是否被绕过、品牌影响是否被错误忽略。
- **外部执行主体**：各平台定价后台/API——当前未授权连接；价格动作只以 Action Intent 存在。

## 业务闭环

1. **STG-01 信号接收**：价格/促销/毛利/库存/竞品信号按 SKU×渠道 聚合；促销日历节点与异常信号分别建档。
2. **STG-02 建单**：Case Charter 固定主价值流（FLOW-01 或 FLOW-03，不可兼）、主场景 SCN-010、范围（SKU 集合/渠道/价格带/时间窗）、毛利底线与价格纪律声明。
3. **STG-03 上下文装配**：固定结果负责人 Release Bundle；装载价格诊断与弹性评估 Skills；只读价格/成本/库存/竞品工具；品牌价值主张与价格感知基线版本。
4. **STG-04 证据与诊断**：AGT-026 组织 Price Evidence Pack（成本结构、当前价、竞品价、库存压力、历史响应）；结果负责人形成 Diagnosis Record——区分「价格问题」（定价错误）与「价值问题」（价值主张未传导）；促销方案按「毛利贡献 × 库存消化 × 品牌感知成本」三维评估。
5. **STG-05 方案产物**：「价格行动包」——候选动作（调价/促销深度/券规则/渠道对齐）、逐对象预期（销量、毛利额、库存周转）、约束校验结果（毛利底线/MAP/渠道纪律）、停止条件；每条标注可证伪条件。
6. **STG-06 Assurance 门禁**：确定性校验（毛利不破底线、价格纪律不违、schema、口径一致）+ AGT-005 语义复核（弹性假设是否有据、叠加规则是否可控、品牌影响是否被显式声明而非忽略）。
7. **STG-07 受控动作**：获批方案拆为逐对象 Action Intent → Policy Gate 判定 → Execution Broker 执行 → 逐对象回执（改价生效确认/促销状态/券发放）；拒绝/异常记入 Case Ledger。当前阶段无授权连接时全部 `NoActionRecord`。
8. **STG-08 核验与关闭**：回执与价格生效核验；当期 GMV/毛利/库存结果复盘；价格感知影响移交关联 FLOW-09 Case 核算；关闭后学习提取回流（哪些价格动作沉淀了感知、哪些透支了）。

## 授权与例外

- **允许**：只读价格/成本/库存/竞品/规则数据；产出诊断、价格行动包与 Action Intent；跨 Case 引用已验收 Artifact。
- **冻结条件**：成本或毛利数据缺失；价格纪律/MAP 文件未版本化；库存约束不可得且方案依赖清货；渠道价格冲突未裁决；品牌感知基线缺失导致无法评估 L2 影响。
- **高风险动作分级**：单 SKU 降幅超 Charter 声明阈值、全渠道同步调价、涉及 MAP 边界的促销——一律逐对象单独审批，不批量放行。
- **重复与部分失败**：同 `case_dedupe_key` 关联既有 Case；部分渠道数据缺失时只冻结受影响渠道分支；Worker 产物不合格退回 STG-04。

## 接管与恢复

- 停止条件：连续两轮补证不满足最小输入；发现成本/价格系统性口径错误；价格动作被判定超 Charter 且无降级方案；平台发出价格违规警告。
- 冻结范围：仅冻结受影响 SKU/渠道/促销分支；已执行的 Action Intent 由执行方 Recovery Contract 负责回滚（改价回退/促销提前结束），本 Case 只引用回执。
- 已产生外部效果：价格变更、促销上线、券发放——需逐对象回执可对账；价格已生效但效果未核验的记 `pending_verification`，不得计入结果。
- 恢复：冻结解除后从断点继续；Price Evidence Pack 版本化保留；价格回滚动作同样走 Action Intent + Policy Gate，不允许人工绕过。

## 验收与经济性

- **产物验收**：Price Evidence Pack 来源齐全率 100%；每个价格假设带毛利测算、约束校验结果、可证伪条件与停止条件；量化表述三级来源标注；品牌影响显式声明（哪怕结论是「本次不评估 L2」也要写明理由）。
- **经营指标**：毛利额与毛利率变化、库存周转改善、价格违规事件数、渠道价格一致性达标率、促销 ROI 口径一致性。
- **双层 KPI 关系**：FLOW-01 绑定时验收看当期 GMV/毛利/库存结果，价格感知只作护栏（大促后 L2 代理指标不得异常恶化）；品牌资产影响经 `correlation_id` 移交 FLOW-09 Case 单独核算，不在本 Case 归因。GMV 升而价格感知降的冲突信号触发 AGT-005 复核。
- **经济性门槛**：首个周期以「毛利测算经财务复核 + 价格纪律校验通过 + 所有价格动作可对账可回滚」为验收前提。
- **必须回放**：促销叠加导致实际到手价破毛利底线（应被确定性校验拦截）；MAP/平台定价违规动作被提交（应被 Policy Gate 拦截）；用历史相关性冒充价格弹性因果；书中「价值感>价格」被当作可计算公式而非原则。
