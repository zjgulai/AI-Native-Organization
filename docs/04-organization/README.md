# AI组织责任与外部执行

状态：D-020与D-021已确认50个逻辑岗位分身、单Case Agent以及5/35/5/5四平面组织视图。真人负责人和HITL后置；尚无已批准的人事调整或编制目标。

当前组织设计只处理三件事：

- 50个AI岗位如何进入经营管理、业务运营、独立控制和数据与Agent平台四个责任平面。
- 现有部门职责如何进入50个AI岗位、Skills和工具能力。
- 哪些步骤必须由企业系统、供应商、受控外部服务或合格执行主体产生回执。

不把真人设置为初始工单的默认负责人、审批者或接管者。未来如要启用HITL、值班、专业复核或组织变更，须基于运行数据、具体动作策略和独立决定单独设计。

[AI组织责任图](AI-ORGANIZATION-MAP.md)是四平面主视图，[部门职责承接表](RESPONSIBILITY-MAP.md)记录现有职责与外部执行边界；AI岗位本身归属[AI分身目录](../05-agents/README.md)。

管理层（1个CEO + 2个二级负责人：增长官、治理官）是**决策权平面**而非Agent层级：它通过版本化契约与资源配额生效，不参与Case执行链、不与岗位发生会话、只读聚合视图。设计与资产见[管理层设计](MANAGEMENT-LAYER.md)、[决策权阶梯](management/DECISION-RIGHTS.md)与[管理层资产目录](management/management-catalog.json)；决定依据见[ADR-0014](../adr/0014-management-decision-rights-plane.md)。
