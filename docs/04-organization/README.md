# 外部执行与未来真人组织

状态：初始运行采用50个Agent自主闭环，真人负责人和HITL后置；尚无已批准的人事调整或编制目标。

当前组织设计只处理两件事：

- 现有部门职责如何进入50个AI岗位、能力包和工具能力。
- 哪些步骤必须由企业系统、供应商、受控外部服务或合格执行主体产生回执。

不把真人设置为初始工单的默认负责人、审批者或接管者。未来如要启用HITL、值班、专业复核或组织变更，须基于运行数据、具体动作策略和独立决定单独设计。
