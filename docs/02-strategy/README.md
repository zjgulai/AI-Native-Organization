# 经营目标与经济性

状态：GMV第一优先级、约50个AI岗位和Agent-first自主运行框架已确认；[总体方案](BLUEPRINT.md)与[容量和成本模型](CAPACITY-AND-COST.md)已形成。金额口径、约束阈值、真实负荷和首批系统连接仍待确认。

## 需要形成的内容

- 50个AI岗位、既有能力包、运行实例与外部执行边界。
- 收入、利润、现金流、服务质量、品牌价值与机会响应速度的优先顺序。
- 按场景核算任务量、人工处理时间、等待时间、返工率和例外工作量。
- 对比当前与目标总成本：模型、软件、数据、集成、外部执行、自治异常、事故损失和迁移投入。
- 不同自动化覆盖率、例外率、旺季峰值下的人员容量和成本区间。

## 必须经数据检验的假设

“50种AI岗位足以覆盖识别出的数字工作”“AI节省的时间可以转化为实际费用节省”“增加并发能缩短经营等待”均属于待验证命题。用户没有要求真人总数必须为50，不能按此目标倒推缩编。

初步测算应分别列出Agent任务、工具调用、外部执行、异常冻结/恢复、峰值与固定支持职责，防止用平均值掩盖接口限流或单点依赖。未来HITL或真人组织设计另行建模，公式和阈值在基线明确后再定。
